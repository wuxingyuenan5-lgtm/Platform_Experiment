- 当前仓位由后端快照选择口径：Cross/只读账户使用场所同步仓位，Funding 等交易策略使用策略归属仓位；前端不再以历史 finance 覆盖空当前仓位。账户同步失败保留最近成功帧并标记过期，历史/结算失败与当前账户不可用分开报告。规则由[账户观测合同](../contracts/LIVE_ACCOUNT_OBSERVABILITY.md)维护。
- Cross 已接入原生 Bybit Chase、MT5 Tick 新鲜度、真实 Venue 规格与交易时段判断，并区分可观察报价和双边可执行状态。未知结果、幂等、终态实际量对冲和指定 Ticket 归属继续由[Cross 执行合同](../contracts/CROSS_SPREAD_EXECUTION.md)及[执行风险合同](../contracts/EXECUTION_RISK.md)约束。
- MT5 固定账户 Worker 已移除 Runtime 预启动与重复初始化链，SDK 负责一次启动/连接；后台窗口隐藏，失败使用 2–30 秒退避。短时加载后仅一个对应 Terminal，连续账户读取成功；长期自然运行与真实成交质量仍未证明。
- 数据库当前迁移链以 `platform-api/app/schema_migrations.py` 为准，现有业务 owner 已通过独立[研究 workstream](strategy-market-research.md)加载追加迁移 30，保持既有交易耐久参数；旧文档中的“迁移 25/26/27 当前版本”是历史快照，不能作为现状或恢复前置。
- 2026-09-19 已核实服务生命周期：`dev-platform.ps1` 负责三服务生命周期，watchdog 执行健康探测与受控恢复，supervisor 只维持 watchdog，pulse 负责触发 supervisor。重复恢复、失效父 PID 判据和临时管道日志问题已修复，服务日志改由受管子进程直接持有文件。三服务重载及一次 pulse 触发链已通过；连续运行仍待验收。Live Write 开启时仅静态 Web 可独立恢复，API/Runtime 中断受[账户观测合同](../contracts/LIVE_ACCOUNT_OBSERVABILITY.md)禁止；合同与代码在此点一致。

- 策略展示与验收入口已修通：读取失败与未绑定分开，Cross 单腿数据不冒充双腿合计，原币持仓价值不强制标成 USD；Funding 账户日历与策略收益保持各自来源。后台刷新保留指标和日历选择，策略管理窄屏与导航关闭可操作。visual 验收使用独立端口、每轮新数据库和 fake Runtime，禁止复用服务或读取业务 dotenv。
- 终端弹窗已定位到交互式计划任务直接创建 PowerShell 控制台，复现时业务服务 PID 未变。任务改为无控制台创建，等待器通过 Windows Job Object 管理直接工作进程；停止 supervisor 不连带停止 watchdog/业务服务。旧 PowerShell 任务入口不得重新导入；维护方式由[运行手册](../operations/RUNBOOK.md)维护。
- 权限已按数据库策略定义覆盖所有 Cross/Funding 实例，不能通过改实例 ID 或旧公共写入口绕过专用链路。资金费归属移除了“历史标的唯一使用者”推断，只接受订单关联或正式归属事实；缺失证据保留在账户层及待归属提示。

## 外部建议复核

| 建议 | 当前代码结论与处理 |
|---|---|
| 保留 Web/API/Runtime 与模块化单体 | 适用；本次根因在任务进程所有权、授权与结算归属，没有引入微服务、消息总线或策略 DSL 的依据 |
| Cross lifecycle 权限缺失、旧入口绕过 | 前半已过时：现有专用开平仓已过 CEO 边界；默认实例 ID 判定仍有漏洞，已按真实策略定义补齐，并验证拒绝前无订单/资源副作用 |
| 前端猜成交、铺平历史浮盈、共享账户充当策略收益 | 所举旧实现多数已移除；保留既有后端读模型与账户/策略分离。另复现后端无依据分配资金费的问题，已修复 |
| 建立策略净值或分配账户全部收益 | 缺少资本分配与结算证据时不成立；不新造净值或把待归属结算当成零/已确认收益 |
| 强行统一 Funding/Cross 执行或双腿盲目并行 | 无当前必要性；保留策略特有执行语义、成交量释放和未知结果保护，以已有幂等/批次/风控回归验证 |
| 区分实现、加载与实盘经济验收 | 适用；本轮有隔离测试、本机计划任务及 API 加载证据，无新增真实交易或 Funding 结算经济验收 |
