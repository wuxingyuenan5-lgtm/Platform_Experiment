## 已加载结果

- MT5 只处理配置绝对路径对应的终端。启动与重连恢复隐藏，Worker 在一秒 IPC 轮询边界检查可见窗口；不修改自动交易权限或重复登录同一账号。
- 普通维护从两个运行后端读取一致交易模式并保留；不一致或读取失败在停止服务前报错，冷启动默认只读。当前冷启动两交易开关均关闭；退出监控是否有效以健康接口的最近成功评估为准，启动日志不代表有效评估。
- Cross 的正报价不再单独证明可执行。Runtime 以原生报价时间、MT5 品种模式及账户/终端/EA/Python 权限生成开平能力；休市或单腿受限时继续价差、仓位、保证金和爆仓风险监控，但正常开平及 TP/SL 在领取计划前停止。页面交易规则保留原五行简表，只用两腿真实 Instrument Specification 和市场状态填充交易时间与数量限制，后台准入证据不在表内展开。
- Cross 领取退出计划前检查开关，异常路径保留实际 Close Batch；历史未派单计划仅在事务证明没有指令/订单后人工恢复。已成交 Bybit、未派单 MT5 的恢复沿原指令、命令和幂等键完成，未知结果禁止重放。
- Funding/Cross 的正常持仓、订单、成交和异常按开仓指令及批次归属；共享账户或同一品种不改变策略归属。异常卡无内容时隐藏，正常一键全平排除异常组；损益缺失不补零。
- Funding 新开仓以现货毛数量扣除已确认的 0.1% 基础币费率，再向下取永续步进；确认页冻结两腿数量，低于最小数量时拒绝。累计现货释放按冻结比例，实际净币量继续按原生费用核对。卖出及永续 USDT 费用不再次扣 BTC；既有异常组不按新规则重算。
- 各策略订单共用开平汇总、逐笔成交、委托、筛选和展开详情；策略选择以 URL 为单一来源，加载中、未绑定和历史载入范围明确展示。开平优先取业务指令、只减仓或原生 MT5 进出场标记；旧无依据记录继续待核对。
- Bybit 订单读写保持明确账户及市场；MT5 原生源时间稳定保存、观察时间独立。已接受的历史时间差异只影响有效读取，原始回执不改写。账户同步最近成功数据持续更新，失败保留旧快照并标注过期。
- MT5 报价在读取时核对终端的经纪商连接，断线/信息缺失时拒绝 SDK 留存的正数 Tick；连接恢复后的读取可继续。CEO 的 Runtime Journal 恢复与 Venue 对账共用既有复核权限，保留 CSRF、禁止重提订单及缺失订单接受边界。
- 第二版采用现有执行引擎与公共组件；NautilusTrader 试点因精度合同不满足已结束。CCXT 只负责标准行情/规格，Runtime 独占订单副作用。生成 API、共享连接、指令缓存及策略财务归属已接入，详见系统地图及执行合同。

本轮追加（2026-09-11）修复与扩展：

- 抄底监控账户的仓位分布此前为空。原因是该账户无 `contract_specifications` 记录，交易所上报的逐腿估值字段也未被平台保留。运行时现已保留交易所上报的持仓价值；平台侧 `monitor_position_valued` 对缺乘数的标的按线性类型归 1，逐腿回填自身估值并汇总账户级敞口（多腿合计仍在同一原币内，不混算）。真实账户数值与页面展示仍须在加载新构建后只读核验。
- 后端账户快照新增 `dailyPnl`：逐 UTC 日取同资产域、同币种最后一条有效权益，按日收盘权益差减区间净资金流得到当日盈亏与收益率，复用既有资金流分类与汇率估值规则。区间不串联（某日不可估值不抑制次日），不可估值日返回 null 加 `quality` 原因而不是 0；最新一日在上游发布前保持待定。Owner 2026-09-11 确认口径包含浮盈浮亏及手续费、资金费、库存费。口径归账户观测合同。
- Cross 损益页现在把绑定的 Bybit 与 MT5 两条策略腿按 UTC 日期合并为一个策略日历；同币种时合计两腿盈亏，并以两腿期初权益计算收益率。缺腿或币种不一致时该日收益率保持不可用，不混入 Funding 或其他策略。
- 损益页新增每日盈亏日历：可按月翻页；点击标题在「按日 ⇄ 按月」之间切换；月视图按年翻页，翻页到当月/当年为止。沿用策略模块既有配色（盈利绿、亏损红）与 `--strategy-*` 变量；不可估值日灰显，悬浮提示给出后端质量原因；月度/年度收益率在区间内存在未估值日时显示 `--`。默认落在最近有数据的月份，用户手动翻页后不再被刷新拉回。
- 账户资金新增「单边资金利用率」（占用保证金 / 账户权益；对冲类账户按单边口径标注）与「爆仓价」卡片。交易所未上报逐腿爆仓价的账户显示 `--` 并注明按账户级风险率强平，不猜测或推算价格。Bybit UTA 不提供逐腿占用保证金，对冲账户该卡片分子仍是共同保证金池，此点待 Owner 确认是否可接受。

验证：本次复核的后端资金费、账户快照与财务读模型定向 pytest 共 52 项，以及相关 `ruff check` 均通过；前端策略类型检查、生成 API 合同 `--check` 与跨所价差接线脚本均通过（11 项）。本轮复核修正了盈亏日历含不可估值日仍计算区间收益率的问题，并补充回归；海外面板已接入宏观/加密页，缺失 ZQ 结算值保持 null。前端完整类型、海外研究 24 项测试与生产构建通过。真实浏览器目视验收和新海外源的外部数据覆盖仍待后续运行条件。
