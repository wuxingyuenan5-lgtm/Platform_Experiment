# 对冲基金看板验收手册

> 适用基线：Platform 0.9.1 候选版本  
> 任务：Issue #132  
> 状态：自动化验收建设中；真实数据与人工视觉结果必须在实际运行环境记录。

## 1. 验收边界

本手册覆盖：

- A股市场表现、市场广度、市场明细；
- 申万一级、申万二级与个股成交额阈值统计；
- 短线情绪；
- 账号级自选股；
- 一键个股数据；
- 宏观事件概率；
- 外部免费研究数据源的状态、降级和最后有效数据。

本手册不覆盖：

- 真实下单、订单、成交、持仓和会计账本；
- Execution Runtime；
- 将投研行情认定为交易执行权威行情；
- 对第三方免费数据源的永久可用性承诺。

## 3. 真实研究数据探测

先启动Platform Backend，再执行：

```powershell
cd platform-backend
python scripts/validate_research_sources.py `
  --base-url http://127.0.0.1:8000 `
  --stock-code 600519 `
  --threshold-yuan 10000000000 `
  --output ../artifacts/hedge-board-live-source-check.json
```

启用生产API Key时使用：

```powershell
python scripts/validate_research_sources.py --api-key "<临时注入，不写入仓库>"
```

使用浏览器会话时，可传入临时会话Token：

```powershell
python scripts/validate_research_sources.py --session-token "<临时会话Token>"
```

该脚本只通过Platform API检查：

- API契约；
- `source`、`sourceTimestamp`、`fetchedAt`；
- `ready / partial / stale / no_data / error`；
- 模块和行数；
- 申万未匹配证券数量。

脚本不能替代人工判断价格和市场口径是否正确。

## 4. 人工业务验收

### 4.1 交易时段

- [ ] 大盘表现至少返回上证指数，并保留中证2000。
- [ ] 收盘价、涨跌幅和成交额与一个可信行情终端抽样核对。
- [ ] 20日波动率抽样取一项，用21个有效收盘价复算。
- [ ] 上涨、下跌、平盘家数之和与市场覆盖范围相符。
- [ ] 涨停、真实涨停、炸板、跌停和连板梯队与当日市场抽样核对。
- [ ] 申万二级默认按成交额Top 10展示。
- [ ] 全部申万二级支持一级筛选、名称/代码搜索和升降序。
- [ ] 50亿元、100亿元、200亿元和自定义阈值均严格使用 `>`。
- [ ] 点击行业数量能展开具体股票。
- [ ] 复制统计与CSV导出的数量、行业和口径一致。
- [ ] 未匹配申万分类的证券有明确记录，非零结果逐项核查。

### 4.2 非交易时段

- [ ] 数据时间明确显示上游时间和平台抓取时间。
- [ ] 不将上一交易日数据伪装为实时数据。
- [ ] `stale`状态清晰可辨。
- [ ] 暂无数据与接口错误的视觉状态不同。
- [ ] 空拉取不覆盖最后一份有效数据。

### 4.3 一键个股数据

至少抽样：沪市主板、深市主板、创业板各一只。

- [ ] 支持 `600519`、`SH600519`、`600519.SH`等输入并归一化。
- [ ] 新查询后所有数据模块默认折叠。
- [ ] 某一数据源失败不导致整页失败。
- [ ] 行情、财务、估值、公告、研报等模块显示真实来源。
- [ ] 研报、公告和新闻原文链接能够打开。
- [ ] 连续快速切换股票时，旧请求不覆盖最后一次查询。

### 4.4 账号级自选股

- [ ] 添加、删除、分组和组内排序后显示“账号已同步”。
- [ ] 明确保留空自选股列表。
- [ ] 关闭当前浏览器会话，在新浏览器会话登录同一账号后恢复数据。
- [ ] 不同账号的自选股相互隔离。
- [ ] 后端临时不可用时，本地缓存仍可使用并显示“本地缓存·待同步”。
- [ ] 后端恢复后，本地变更可重新同步。

### 4.5 视觉与响应式

分别检查1440px、1024px、768px和390px宽度：

- [ ] 表格横向滚动不破坏页面布局。
- [ ] 数值右对齐，名称左对齐，空值统一为“—”。
- [ ] 红涨绿跌符合平台约定。
- [ ] 筛选、应用、复制、导出和展开操作易于识别。
- [ ] 页面没有重叠、截断、白屏或明显布局跳动。
