## 四、A股真实数据验收

### 4.1 市场概览与明细

- [ ] 上证指数、沪深300、上证50、创业板50、科创50、中证500、中证2000和中证A50均能显示；
- [ ] 收盘价、成交额和涨跌幅与同一时点公开行情基本一致；
- [ ] 20日波动率使用至少21个有效收盘价，数据不足时显示“—”；
- [ ] A股表格不存在4H列，1H、日线、3日线和周线状态正常；
- [ ] 交易时段刷新与收盘后刷新均不会整页白屏。

### 4.2 市场广度与短线情绪

- [ ] 上涨、下跌、平盘、涨停、真实涨停、跌停和真实跌停数量合理；
- [ ] 市场宽度分类与既定阈值一致；
- [ ] 封板率、炸板率和晋级率的分母为零时显示暂无数据，而不是虚假0%；
- [ ] 连板梯队和最高连板与当天公开涨停池基本一致；
- [ ] 非交易日能够返回最近有效交易日或明确暂无数据。

### 4.3 申万行业与成交额阈值

- [ ] 行业归属维度为申万一级、申万二级，不使用东方财富行业分类替代；
- [ ] 申万二级默认Top 10按行业总成交额降序；
- [ ] 一级筛选、二级搜索、排序字段和升降序均有效；
- [ ] 筛选后的“当前序号”连续且不展示失真的原始排名；
- [ ] 50亿元、100亿元、200亿元和自定义阈值可正常刷新；
- [ ] 判定严格使用“个股成交额 > 阈值”，等于阈值的股票不计入；
- [ ] 点击行业数量可以展开具体股票；
- [ ] 复制统计和CSV导出内容、日期及中文编码正确；
- [ ] 未匹配申万分类的证券数量处于可接受范围，并保留待匹配清单。
