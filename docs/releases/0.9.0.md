# Platform 0.9.0

Release date: 2026-07-26

## Included

- unified four-action cross-spread intent model;
- protected Market execution with confirmed Bybit Fill before MT5 hedge;
- FOK spread-limit Open and Close;
- persisted TP/SL Market or Limit execution selection;
- disabled-by-default bounded Bybit PostOnly Chase with private Order/Execution evidence;
- lean Fast / Standard / Critical engineering workflow;
- path-scoped pull-request CI and one dedicated Secret Scan;
- smaller Agent context and stable current-state documentation;
- one-command Windows local startup with tool-version alignment and health checks;
- one-command synchronized product-version updates.

## Safety unchanged

- Platform and Runtime Live Write remain disabled.
- Automatic cross-spread exit monitoring remains disabled.
- PostOnly Chase remains disabled until controlled operational acceptance.
- The 1 oz and single non-closed lifecycle restrictions remain.
- This release is an engineering baseline, not proof of real Bybit/MT5 acceptance.

## Deferred

Execution-quality and fee-review fields remain Markdown-only candidates pending a later product-placement decision.
