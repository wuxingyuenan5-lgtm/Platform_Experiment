# Platform 0.7.0

Release date: 2026-07-25

## Release scope

Platform 0.7.0 consolidates the maintained engineering baseline completed through EOD Reconciliation Service extraction and establishes one product release identifier across maintained components.

## Included

- Root `VERSION` is the canonical product release version.
- Platform Backend and Execution Runtime package versions are aligned to `0.7.0`.
- The frontend displayed version is aligned to `0.7.0`.
- CI checks release-version consistency.
- The unused frontend legacy single-order submission client and submit-state hook path are removed.
- Maintained funding execution continues through ExecutionBatch.

## Compatibility retained

The Backend deprecated `POST /api/v1/trading/orders` compatibility endpoint and `trading.submit_order` delegate remain available. They are still covered by recovery and safety tests and may have consumers outside this repository. Their removal requires separate usage evidence and migration work.

## Unchanged behavior

- No trading, order recovery, reconciliation or accounting behavior changed.
- No database schema or migration changed.
- No Platform–Runtime V1 contract changed.
- Platform Live Write and Runtime Live Write remain disabled by default.

## Version semantics

`VERSION` represents the product release. FastAPI application metadata and explicit API/contract versions represent component compatibility and are not required to match the product release number.
