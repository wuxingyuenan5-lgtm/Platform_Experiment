# Platform Experiment 0.9.1

发布日期：2026-07-29  
客户系统交付分支：`feature/issue-117-platform-0-9-1`  
对冲基金看板最终候选分支：`feature/issue-130-hedge-board-release-readiness`  
基线 `main`：`a4e22021c71cf5cd703cb0bc35676ff5adbfec36`

## 发布定位

0.9.1 是独立集成版本，不自动合并 `main`。它以最新上传的 0.9.0 平台为基础，保留对冲基金看板、资金费、跨所价差、Runtime 和本地启动体系更新，并接入完整浏览器用户系统。

后续对冲基金看板候选分支在0.9.1客户系统基础上继续补充投研数据、宏观概率、A股研究、自选股账号同步和专属浏览器验收。所有候选分支与Draft PR保持未合并，直至项目所有者明确批准。

## 用户系统

- 浏览器注册、登录、退出、重新认证和一次性密码重置凭证；
- Argon2id 密码；
- HttpOnly Cookie Session；
- CSRF、Origin 和登录限流；
- CEO、技术负责人、员工、会员四种固定业务角色；
- 用户搜索、筛选、审批、角色和状态管理；
- 用户详情、头像、设备 Session 和管理员运营备注；
- 密码、角色和状态变更后的旧 Session 撤销；
- 技术负责人目标范围、员工脱敏和会员数据隔离。

## 会员资产

- 会员本人基金持仓；
- 基金单位净值；
- 账户估值、累计投入和累计收益；
- NAV 可用、过期和缺失状态；
- Decimal 字符串精度；
- CEO 后台 `manual_admin` 维护边界。

## 对冲基金投研看板

- A股市场概览、市场广度、指数明细、中证2000和20日波动率；
- 申万一级、申万二级、成交额Top 10和独立个股成交额阈值统计；
- 短线情绪、连板梯队、封板率、炸板率和晋级率；
- 一键个股客观数据，包括行情估值、财务、估值分位、研报、公告、资金筹码和申万归属；
- 宏观市场预期与事件概率曲线；
- 免费研究Provider、TTL、模块独立失败和Last Known Good；
- 自选股按用户账号持久化，保留本地缓存与网络失败降级；
- 账号自选股使用乐观版本控制，防止多个页面或设备静默覆盖；
- 对冲基金看板专属Playwright浏览器验收；
- 免费Provider可选真实网络烟雾脚本，不将外部接口可用性设为基础CI硬依赖；
- 研究数据继续与Execution Runtime和交易权威行情隔离。

## 平台融合

- 保留最新 `main` 的对冲基金看板和研究子导航；
- 保留资金费执行面板与持仓/状态拆分；
- 保留跨所价差页面、执行指令、行情与分析组件；
- 保留 Execution Runtime 的 Bybit、MT5 和跨所行情更新；
- 保留统一 `scripts/dev-platform.ps1` 启动路径；
- 登录页沿用新版视觉，认证切换为 Platform Backend Cookie Session；
- 前端用户系统脚本、看板浏览器E2E与最新布局守卫共存。

## 安全边界

- API-Key 角色与浏览器业务角色保持独立；
- API-Key `admin` 不等于浏览器 CEO；
- Browser Session 不能调用现有 Live Write 路由；
- LiveTradingSession、Kill Switch、对账、绝对限额和 Runtime Live Gate 保持不变；
- Platform 和 Runtime Live Write 默认关闭；
- 演示账号不得进入生产环境；
- 免费研究数据不得直接成为下单、风控或正式会计事实。
