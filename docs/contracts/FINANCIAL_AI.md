# Financial AI Contract

状态：`active contract`

## 接口与权限

`/api/v1/financial-ai` 下的配置状态、能力检测、全球证券、资讯雷达、连接测试和普通分析使用 `platform:read`。保存或替换 `PUT /connection`、清除 `DELETE /connection` 使用现有 `settings.write`；页面不定义私有角色。Guest、会员、员工、viewer 等不具备该管理写权限的主体不得修改机器级配置。可选网关密钥只是请求二次校验，不改变上述权限。

## 分析流与失败

`POST /chat` 以 NDJSON 返回 `delta`、`done` 或 `error`。API 连接为 15 秒、整体读取为 90 秒超时；CLI 连续 300 秒无输出则终止子进程并返回失败。浏览器取消必须中止当前读取；断线、非 2xx、上游拒绝、超时、无配置或 CLI 退出均是显式失败，不得补入伪造结果。已接收的部分文本不代表任务完成。

## API Key 生命周期

网页提交的 Provider API Key 由 Platform API 写入本机忽略目录中的私有配置文件，不写入浏览器持久化、平台数据库、日志或 Git。读取只返回是否已配置及非敏感元数据，永不返回 Key 的值、长度、前后缀或哈希。留空 Key 的再次保存保留原 Key，非空值原子替换，显式清除删除该本机文件。受支持的操作系统上应将文件权限限制为运行账号可读写。

## 订阅 CLI

只允许服务端固定白名单中的 Claude Code、Qwen、DeepSeek 和 Codex 可执行文件及固定参数。浏览器只能选择枚举项，不得提供可执行路径、shell、参数、工作目录或环境变量；禁止任意命令执行。“已安装”只是能力检测，不是登录、配额或真实生成成功证据。

## 数据语义

- 全球证券快照使用平台研究接口以及 Eastmoney、Yahoo Finance 等公开上游，返回来源、源标的、周期及上游时间。各市场交易时段、延迟和报表期不同，因此“最新”不等于实时。
- 资讯雷达聚合固定公开 RSS 来源，保留来源、原文链接与发布时间；进程内缓存 5 分钟，用户主动刷新可跳过缓存。单一来源失败只影响相应分组，响应必须保留其他成功来源并显示可识别的缺失。
- 当日复盘只基于当次用户更新得到的 A 股市场、行业、情绪及 Macro、Commodity、Crypto 底稿。每个底稿保留自身来源和时间；部分来源失败时只能分析已成功底稿，并显式标注缺失。页面不得以进入动作自动刷新上游。

缓存时间、生成时间和上游业务时间必须分开表达。任一上游或模型的部分成功不能被扩大为全链路成功。

## 非事实边界

模型输出是待人工复核的研究内容，永不是订单、成交、PnL、NAV、风险状态或会计事实，也不能赋予任何 Live Write 权限。
