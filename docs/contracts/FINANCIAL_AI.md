# Financial AI Contract

状态：`active contract`

## 接口与权限

`/api/v1/financial-ai` 下的配置状态、能力检测、全球证券、资讯雷达、API 连接测试和普通 API 分析使用 `platform:read`。订阅 CLI 的分析及连接测试还要求现有 `settings.write`，因为它使用服务运行账号的本机订阅身份。保存或替换 `PUT /connection`、清除 `DELETE /connection` 同样使用 `settings.write`；页面不定义私有角色。不具备该管理权限的主体不得修改机器级配置或调用机器 CLI。可选网关密钥只是请求二次校验，不改变上述权限。

## 分析流与失败

`POST /chat` 以 NDJSON 返回 `delta`、`done` 或 `error`。API 连接为 15 秒、读取等待为 90 秒超时；CLI 总运行时间限制为 300 秒，包括输入、输出和退出等待。取消、断线、超时和生成器关闭均须终止并回收 CLI 子进程树、排空管道；stderr 并行读取且只保留有界尾部，不将可能含认证信息的原始错误回传浏览器。断线、非 2xx、上游拒绝、超时、无配置或 CLI 退出均是显式失败，不得补入伪造结果。已接收的部分文本不代表任务完成。

## API Key 生命周期

网页提交的 Provider API Key 由 Platform API 写入本机忽略目录中的私有配置文件，不写入浏览器持久化、平台数据库、日志或 Git。读取只返回是否已配置及非敏感元数据，永不返回 Key 的值、长度、前后缀或哈希。留空 Key 的再次保存保留原 Key，非空值原子替换，显式清除删除该本机文件。受支持的操作系统上应将文件权限限制为运行账号可读写。

## 订阅 CLI

浏览器只能选择服务端枚举，不得提供可执行路径、shell、参数、工作目录或环境变量。Codex 固定使用只读沙箱、忽略用户配置及规则、不持久化会话；Claude 关闭内置工具、MCP、hooks、skills 和会话持久化。Qwen、DeepSeek 尚无已核实的受限调用方式，保留枚举但明确返回不可用，不执行自动批准参数。Windows 只接受原生 exe，不通过 shell 执行 npm 包装脚本。

每次调用使用独立临时工作目录和最小环境，保留系统路径、订阅登录目录以及既有代理/TLS配置；不继承平台令牌、Provider API Key 或运行时注入变量。订阅身份仍属于服务账号，受限参数不是独立租户隔离，因此 CLI 只对机器配置管理者开放。“已安装”只表示原生程序可定位，不能证明参数版本兼容、登录、配额或生成成功。11月4日参数依据本机 Codex/Claude help 核对；当前修订通过本机无害进程替身验证，历史真实调用不替代新参数的外部验收。

## 数据语义

- 全球证券快照使用平台研究接口以及 Eastmoney、Yahoo Finance 等公开上游，返回来源、源标的、周期及上游时间。各市场交易时段、延迟和报表期不同，因此“最新”不等于实时。
- 资讯雷达聚合固定公开 RSS 来源，保留来源、原文链接与发布时间；进程内缓存 5 分钟，用户主动刷新可跳过缓存。单一来源失败只影响相应分组，响应必须保留其他成功来源并显示可识别的缺失。
- 当日复盘只基于当次用户更新得到的 A 股市场、行业、情绪及 Macro、Commodity、Crypto 底稿。每个底稿保留自身来源和时间；部分来源失败时只能分析已成功底稿，并显式标注缺失。页面不得以进入动作自动刷新上游。

缓存时间、生成时间和上游业务时间必须分开表达。任一上游或模型的部分成功不能被扩大为全链路成功。

### 当前存储与更新方式

| 数据 | 当前实现 | 更新与失败语义 |
|---|---|---|
| 机器级 Provider 配置 | 与 `VG_DATABASE_PATH` 同目录的 `financial_ai_connection.json`；API Key 不进入平台数据库或浏览器 | 仅 `settings.write` 的显式保存、替换和清除可修改；采用临时文件原子替换，读取永不返回密钥 |
| 浏览器接入状态与研究记录 | 订阅/接入偏好、可选网关访问密钥、当日复盘、个股分析和资讯笔记当前保存在浏览器 `localStorage`；Provider API Key 不在其中 | 仅当前浏览器来源可见，不是账号级历史、服务端审计或跨设备持久化；清理浏览器数据会丢失 |
| 资讯雷达 | 固定公开 RSS 的请求结果保存在进程内 5 分钟缓存 | 页面请求触发读取，主动刷新可绕过缓存；进程重启即丢失，单源失败保持部分结果和错误证据 |
| 全球证券、复盘底稿与模型输出 | 请求时读取研究/公开上游并以流式响应返回；服务端当前不保存分析结果历史 | 每次分析携带当次输入上下文；取消、超时、断线或部分输出不得记录为完成，也不证明持续采集已部署 |

未来若需要账号级研究历史，应先确认产品范围，再定义用户归属、输入快照、模型版本、权限继承、删除与重放语义；当前浏览器保存和进程缓存不能被当作该目标设计已经完成。

## 非事实边界

模型输出是待人工复核的研究内容，永不是订单、成交、PnL、NAV、风险状态或会计事实，也不能赋予任何 Live Write 权限。
