# Codex Task Template

Use this structure for large changes.

## Goal

One sentence describing the outcome.

## Scope

Allowed:

- files
- modules
- APIs

Forbidden:

- unrelated refactors
- architecture changes without approval

## Context Required

List only required docs and modules.

## Acceptance

- Code completed.
- Tests passed.
- Documentation updated.

## Validation

Record commands and results.

## Rollback

Describe how to revert safely.
