# 商品看板数据源图

本文件保留商品研究的专项来源、许可边界与交付选择；不维护产品范围、阶段进度或通用数据合同。通用规则见 [Research Data Contract](../../contracts/RESEARCH_DATA.md)，用户结果见 [对冲基金看板](../../product/modules/对冲基金看板.md)。

## 口径与限制

- 跨市场价差只有在两个 leg 的许可、币种、合约月份和时间戳都可验证时才本地计算；否则提供原站入口。
- Market Detail 的价格、收益率与小趋势图必须来自同一可追溯历史；没有可靠历史时显示不可用。
- 不新增农产品或把受限商业数据转换为静态快照。
- CFTC 报告按官方报告日显示并标注周度滞后；缺失或过期序列保留来源与状态，不以零值替代。CFTC 数据与商品价格、执行或风险输入保持隔离。
- CFTC 图使用看板窗口内全部周度观测，按实际报告日期绘制并支持时间缩放及原始值提示；图表起止日期与所绘序列一致，空缺不连线。

## 本地公开数据补充

- SPDR 官方 historical-archive XLSX：黄金持仓吨数、连续有效交易日持仓差、GLD 股价；节假日不填零，持仓差不标成美元净流入。
- 金价比较采用 Yahoo `GC=F` 近月黄金期货，和 SPDR 持仓、FRED `DFII10` 分别使用双轴；不冒充现货黄金或 LBMA fixing。
- GVZ 使用 FRED `GVZCLS`。
- COMEX 库存直接读取 CME `Gold_Stocks.xls`，保留注册/合格/总量与活动日、报告日；历史从首次采集积累，Pledged 不再次计入合计。
- GLD 借券读取 ChartExchange 公开的 Interactive Brokers 最新快照，保留来源时间、百分比费率及可借股数；只代表单一券商，未购买旧历史。
- 黄金 OI 目前只覆盖 COMEX GC 与上期所 AU，其他交易所及全球总量仍缺；跨所价差、原站 QuikStrike 等仍未实现本地完整数据/交互。
- 商品明细参与度：GC/SI/HG/PL/PA/CL/BZ/NG 八种连续期货，按同日有效样本的日收盘严格高于 20/50/200 日均线计算。排除纽约当前日期，展示观察日期与覆盖数；不是全商品市场广度。后台计算写入既有 SQLite 快照，GET 不抓取或重算。

- 沪金期限结构：上期所官方日行情 `kxYYYYMMDD.dat`，按实际交割月展示日结算价（元/克），附合约数据表；排除小计，保留交易日，历月合约历史留存。缺失结算价不改用收盘价，失败保留最后完整曲线并标记待更新。2026-10-09 八个 AU 合约已完成真实采集/API 验证。
- WGC 受限 XLSX 下载仍为 HTTP 403。已接通公开月报页面的区域 ETF 周/月 USD 资金流、公开 snapshot 的最新季度国家储备，以及央行月报明确披露的主要国家当月净购买。储备 AWAITED 保留 NULL；月报近似值、YTD 与未披露购买排除，不能合成全球央行总量。公共图表与登录受限下载的覆盖严格区分。

- 沪金期权波动率：上期所期权日行情 `o_cursigma` 的 AU 月份 `SIGMA × 100`，保留官方精度、原始文件及交易日；不是 ATM IV。当前月份清单独立发布，失败保留旧值并标记待更新。
- 黄金持仓：CFTC Disaggregated Futures Only `088691/open_interest_all` 的 COMEX GC 周度持仓（100 金衡盎司/手）与上期所 `au_f` 日度持仓（1000 克/手）分别展示；AU 各合约合计核对官方小计。不混加手数、不合成全球总量。
- 展示参照：2026-10-11 已通过浏览器核对 OpenVlab AU 与 MacroMicro 黄金持仓原图。OpenVlab 为 ATM 隐波、偏度及逐行权价微笑，部分期限为 Pro；本地月份 `SIGMA` 不替代这些指标。MacroMicro 原图为多交易所美元名义持仓堆叠，本地合约手数不等价；未补齐同日估值和交易所覆盖前，保持分市场展示和金额缺口。

## 黄金持仓、研报与分析师

黄金持仓新增 CFTC 官方分项期货、分项期货加期权及传统期货口径，保留约五年周度历史、多空/套利/净头寸、日期对齐的周度与 4/13 周变化、完整 52/156 周净持仓占 OI 分位。Managed Money 期权等价差仅在两口径报告日一致时计算；传统 Noncommercial 不与之混用。

GoldPulse `/api/report/daily` 与 `/api/analysts` 为公开第三方研究来源。商品页已移除黄金 AI 研报区；日报采集归档与只读 API 保留。金属分析师跟踪位于黄金分时累计波动之后，默认折叠，标题栏支持展开/收起；分析师支持作者、方向、关键词和分页，保留期限、条件、原文链接与正文读取状态。上游观点未独立逐篇核验，不能当作官方市场数据或平台自身账户建议。报告采用的持仓日期与最新官方持仓分别展示；无样例回退。产物、归档、失败保留及 API 边界由 RESEARCH_DATA 维护。

黄金多口径持仓并入“商品补充分析”的 CFTC 持仓报告黄金标签页，与白银、铜、WTI、天然气共用一个默认折叠入口；不再单列 CFTC 黄金持仓区。黄金沿用官方分项期货、分项期货加期权、传统期货的独立口径与历史，不将其他商品的分项期货口径套用到黄金所选口径。
