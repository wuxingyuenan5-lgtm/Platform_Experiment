# 风险管理

风险管理是账户、资产、权限、审计、运行和交易风险的内部管理入口。它展示并控制风险，但不替代各领域的业务事实 Owner。

## 用户结果

- 查看账户、资产、敞口、风险状态和异常。
- 管理受权限约束的用户、角色、会话和审批。
- 查看运行状态、审计记录、对账差异和人工处理事项。
- 在授权范围内执行 Kill Switch、确认或修正流程。

## 当前范围

- 风险详情与敞口。
- 账户、资产、资金与财务视图。
- 数据和服务状态。
- 用户、权限、会话、审计和个人账号。
- 对账差异、消息和人工处理入口。

## 边界

- 会员不可见且后端拒绝内部风险管理资源；员工默认只读。
- 前端按钮、菜单和路由不能替代后端授权。
- Kill Switch、LiveTradingSession、审批、数据范围和执行权限相互独立。
- 监控视图不把缺失、陈旧或估算数据显示为正常零值。
- 风险页面不直接持有 Venue 凭据或执行订单。

## 最小验收

- 直接 URL、菜单和 API 使用一致的 Capability 语义。
- 关键风险数值保持 Decimal、币种、单位和带时区时间戳。
- 高风险操作具有明确确认、审计和失败关闭行为。
- 数据缺失、过期、权限不足和系统错误可以被用户区分。
