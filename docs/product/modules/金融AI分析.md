# 金融 AI 分析

金融 AI 分析用于归纳、比较和推演已授权的研究数据。它是辅助分析工具，不是交易、会计或风险事实权威。

## 用户结果与正式能力

- **AI 当日复盘**：用户主动更新市场底稿，生成可追溯、可停止、可保存和导出的结构化复盘，并区分事实、推断与待验证项。
- **个股分析**：查询 A 股、港股和海外证券的行情、图表与研究底稿，运行快捷问题、分维分析和多空观点，并保存研究记录。
- **资讯雷达**：按事件、自选股和行业查看带时间与原文链接的公开信息，支持日期与类型筛选、分组提炼、停止生成和保存研究笔记。
- **接入 AI**：查看模型、订阅 CLI 和数据源状态；有管理写权限的用户可保存、替换或清除本机共享 API 配置。配置后，其他三页共用同一分析能力。

当日复盘、资讯雷达和数据源状态只在用户明确点击更新或刷新后请求上游，不因进入页面自动消耗配额。

## 边界

- 没有真实分析服务、数据源或权限时，必须显示待处理或失败，不得伪造成功。
- 模型输出不能成为订单、PnL、NAV、风险或会计事实，也不能自动触发交易。
- 新闻摘要不替代原始来源；上游时间、缓存和部分失败必须可识别。
- 敏感数据只能在当前用户已授权范围内进入分析；只读用户不得修改机器级 API Key。
- 详细接口、权限、密钥、流式失败与数据语义以 [Financial AI 合同](../../contracts/FINANCIAL_AI.md) 为准。

## 最小验收

- 四个子页的主要读取、分析、取消和保存交互可用，失败有明确状态。
- 关键结论可追溯到来源和时间，推断与待验证项有明确标记。
- 普通分析与共享配置管理的权限边界同时由前端与后端验证。
- 分析失败、取消或超时不会触发交易副作用。
