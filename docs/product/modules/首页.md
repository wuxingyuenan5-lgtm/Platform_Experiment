# 首页

首页是平台的品牌入口与个人工作台，组合展示单张图表、数据表和已有数据库指标，不成为业务数据权威。

## 用户结果

- 快速确认平台当前可用状态和主要市场环境。
- 看到最重要的研究、策略与风险入口。
- 从摘要进入负责该事实的正式模块。

## 当前范围

- 品牌与平台定位。
- 一级模块导航。
- 有明确来源和时间语义的市场摘要。
- 账号独立保存小组件、顺序与半宽/全宽布局；一个组件是一张图、一张表或一个指标，不嵌入完整模块或子页。未授权组件不可选择或显示。
- 自由图表选择已有共享研究指标A/B、原值双轴/基期100/观察期变化率、日期范围；可切换图表或分页数据表，预览、编辑并保存至当前账号。
- 组件库复用可独立展示的研究图表，宽基ETF净申赎图、资金统计表和市值占比图分别选择；原页入口保留。旧整页卡片保留配置并提示选择小组件，不再挂载整页。
- 重要关注事项与风险提示的简要呈现。

## 边界

- 首页复用原组件，进入可视区域后再挂载，不重新计算策略、风险、账户、PnL 或 NAV；自由图表只作研究展示变换，不形成业务金融事实。
- 卡片与事件按服务端认证账号隔离，版本冲突拒绝覆盖；权限降低时隐藏已存卡片，恢复权限后可继续使用。
- 图表编辑器仅开放已登记的共享研究序列，不开放任意SQL、文件路径或他人账户数据。
- 无真实后端来源时显示 `sample`、`unavailable` 或空状态，不伪装成实时数据。
- 首页上的交易入口仍由目标模块重新鉴权和检查 Live Write。

## 最小验收

- 五个一级模块入口清晰且路由可恢复；旧新闻日历路由可以跳转到新的负责模块。
- 摘要状态、更新时间和数据质量不会误导用户。
- 页面不暴露 Provider、Owner、接口名或内部架构解释。
- 刷新或直接访问不会绕过目标模块权限。
