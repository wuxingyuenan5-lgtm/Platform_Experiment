# 首页

首页是平台的品牌入口、市场摘要和工作导航，不是第二个研究终端或业务数据权威。

## 用户结果

- 快速确认平台当前可用状态和主要市场环境。
- 看到最重要的研究、策略与风险入口。
- 从摘要进入负责该事实的正式模块。

## 当前范围

- 品牌与平台定位。
- 一级模块导航。
- 有明确来源和时间语义的市场摘要。
- 宏观日历等重点内容的摘要与前往负责模块的入口。
- 重要关注事项与风险提示的简要呈现。

## 边界

- 首页只聚合展示，不重新计算策略、风险、账户、PnL 或 NAV。
- 无真实后端来源时显示 `sample`、`unavailable` 或空状态，不伪装成实时数据。
- 首页上的交易入口仍由目标模块重新鉴权和检查 Live Write。

## 最小验收

- 五个一级模块入口清晰且路由可恢复；旧新闻日历路由可以跳转到新的负责模块。
- 摘要状态、更新时间和数据质量不会误导用户。
- 页面不暴露 Provider、Owner、接口名或内部架构解释。
- 刷新或直接访问不会绕过目标模块权限。
