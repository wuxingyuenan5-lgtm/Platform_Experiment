# 对冲基金看板

对冲基金看板用于组织宏观、商品、加密、美股、A 股和全球市场研究，帮助用户从变量变化形成可追溯判断。

## 用户结果

- 按资产类别快速发现异常和重要变化。
- 查看指标的时间、来源、单位和数据质量。
- 在宏观页比较美股 SPY、黄金 ETF GLD 和 BTC/USD 的同区间价格表现、共同观测日回撤、近期相关性和美股下跌区间表现；同期美债收益率变化单独按基点展示。
- 将研究上下文带入策略分析，但不直接生成交易授权。

## 当前范围

- 宏观历史图表提供3个月、1年、3年、5年、10年与全部范围，默认5年；数据不足时仅展示实际历史。
- 流动性的中国货币存量合并M2/M1余额、同比、环比及社融存量同比，增长率使用右轴，环比默认隐藏。经济页不再重复展示货币与信用周期；中国工作时间不再展示或更新。
- 美国经济包含ISM制造业和服务业PMI。美元净流动性标明“美元净流动性=资产-TGA-RRP”。

- 宏观、商品、加密、A 股、美股和全球均属于既有看板范围。Owner 于 2026-10-02 明确要求补齐各板块原有 demo 的数据采集、持久化和前端功能，允许自行寻找稳定公开来源；不能仅因过去作为外链就免除数据接入。新的收费、凭据或交易仍需独立授权。
- A 股本轮交付覆盖现有大盘与情绪、成交额与板块资金、历史图表、核心股票池、筛选与近期关注，连同数据采集、持久化、失败恢复和完整浏览器操作。保留平台既有视觉体系，改善信息层级、可读性和交互反馈。

- 商品页提供商品市场明细、黄金、ETF 与资金面、央行储备、持仓、库存、期限结构、波动率和研究入口。

## 数据交付与空态

每个指标或卡片按其可长期维护的交付方式呈现：

- **本地数据**：平台展示有来源、时间语义和质量状态的研究数据；只在数据足以支持该视图时绘制数值、历史或市场明细曲线。
- **外部研究入口**：研究文章、作者、目录和原站专有交互保留精确跳转。原有数值型 demo 应优先寻找可验证来源并落地；尚未接通的数据必须说明真实限制，不把外链当作已完成的数据功能。
- **官方嵌入**：仅在原站明确支持且不改变页面工作流时使用。
- **未配置或不可用**：保留模块语义并清楚说明不可用；不以零值、静态样例或虚构曲线代替。

Market Detail 使用同一指标的可追溯历史计算当前值、区间变化、52 周位置与小型趋势图。没有可靠历史或当前值时，对应字段显示不可用；不同交易日历和低频指标不得被强行补齐为连续行情。

- 宏观：市场明细、流动性、利率、经济、通胀、风险偏好、经济日历、市场预期、研究工具。
- 商品：市场明细、黄金主图、ETF与资金面、金价驱动分析、商品补充分析、黄金分时累计波动、金属分析师跟踪、研究工具。
- 加密：市场明细、BTC主图、资金面、衍生品、期权、链上成本与周期研究、BTC分时累计波动、理财信息、研究工具。
- 美股：大盘表现（摘要下方展示市场明细）、主题产业链、估值、结构与风险、板块轮动；全球：市场明细与区域轮动合为一个子页。
- A股：市场总览、主题与行业、估值、拥挤度、ETF跟踪、股票池、港股观察。总览承接市场摘要、情绪和资金；通信设备、四行业与创新药的成交额/占比/换手图归入拥挤度。ETF跟踪使用平台字体。
- 交易工具：宏观、股市、加密、金属、量化、综合六个分类，各自支持关键词搜索。

市场明细、行业完整列表、ETF持仓及专题内可收起的研究内容默认展开，仍支持手动收起；弹窗和编辑表单由用户主动打开。A股与美股总览小走势图使用固定屏幕线宽的折线，卡片宽度变化不改变描边粗细。

当前资产工作区内切换专题，保留已接入的标的与日期筛选、市场明细排序、图表窗口及滚动位置。近期读过的只读数据短期复用，过期后重新读取；手动刷新重新读取当前内容，保留有效旧数据与来源日期。个人关注与市场布局仍读取账号最新版本后才能修改。全A成交额历史弹窗只在打开时挂载，每页100行；宏观日历仅在进入该专题且展开时创建嵌入。

## 股票市场观察

A股和美股保留原有行情、行业与轮动内容，追加各自的主题产业链、估值和市场结构观察。两地主题使用独立代表观察池，显示环节、成员、覆盖数和重复归属；主题不是完整指数，不把跨主题成交额相加。

A股增加宽基估值、沪深300长期价格与估值、全市场及申万一级行业PE/PB分布、破净比例、成交集中度和宽基成分换手观察。历史不足的分位留空，不把负净资产当作低估值。美股增加等权/市值、小盘/大盘、纳指/标普、VIX期限比值，以及11只行业ETF的均线参与度、信用利差与实际利率；ETF样本不代表全市场个股广度。

估值页只展示一个可切换标的与指标的双轴图，估值曲线叠加对应指数黑色价格线。A股覆盖沪深300、上证50、创业板指与科创50，提供PE TTM、PB MRQ、PS TTM、PCF TTM与股息率；美股覆盖标普500、纳斯达克100、道指与罗素2000，按可获取来源提供历史PE、前瞻PE及其他估值，FY1与NTM分别标识。缺失指标保持空值，离散快照保留实际日期；不把不同估值口径拼接。港股观察提供恒生科技及恒生互联网科技业指数价格走势。中证历史行情滚动PE与近期PE1仍保留独立数据口径。港股信用因子采用人民银行最新月度社融修订及有出处的历史转载，原始来源分别保留，自动采集失败不会被人工补录清除。

港股观察置于A股页，展示指数及香港M2总额同比、内地PPI同比、社零同比、信用脉冲四项月度因子。四项标准化后各占25%，仅在同月数据及历史长度满足时合成；缺项、来源滞后和历史不足明确显示。该指标用于观察，不声明已证明领先预测能力。具体口径与更新边界由 [研究数据合同](../../contracts/RESEARCH_DATA.md) 管理。

## A股机构持仓与ETF跟踪

A股页提供独立的ETF跟踪入口，参照汪汪ETF公开功能，包含分类/代码搜索、按持仓占比排列的标的选择、本浏览器按账户保存的自选、报告期持仓与历史披露、区间价格和份额、估算申赎资金流、对应指数及组内ETF汇总、ETF和指数成分股融资。界面采用左侧纵向联动图、右侧分组趋势表；六项最新指标与近5/21/63个交易日摘要置于图表上方。价格、成交额、份额、申赎、指数与融资共享日期窗口和十字线，可通过日期输入、双滑块、Ctrl滚轮缩放及拖动平移查看。右侧趋势表拥有独立日期范围，默认最近5个交易日，提供分组合计、成员每日数据、历史分位着色、融资摘要与全屏查看；持仓一览可展开。保留原有股票池与市场观察区，不展示参考站广告、付费推广和互动运营内容。

汇金/证金持仓与险资/国资观察分开标识。报告期、行情日及融资日分别展示；份额变化估算的资金流不代表特定机构当日买卖。无日度数据的目录条目仍显示披露信息；分组汇总缺少成员数据时不显示不完整合计。来源和计算口径见研究数据合同。

## 研究入口与安全边界

- 外部网页不继承平台登录态、浏览器凭据、Cookie 或任何写入权限；个人模板仅作为可公开访问的链接时才可作为入口。
- 研究入口、经济日历和理财信息只服务观察、比较与复盘，不构成交易建议、收益承诺、申购入口或交易授权。
- 看板可以把稳定研究上下文带入策略分析；目标模块仍须独立鉴权，且看板本身不产生订单、持仓、正式 PnL、NAV 或执行状态。

## 边界

- 研究数据、样例数据和不可用状态必须显式区分。
- 外部链接不继承平台登录态、凭据或写入权限。
- 理财信息是研究和比较材料，不构成收益承诺、推荐、申购入口或交易授权；缺少来源、截止时间或真实数据时必须明确标记。
- 看板不拥有订单、持仓、正式 PnL、NAV 或执行状态。
- 指标修订和缓存不能静默覆盖原始时间语义。
- 明细区分盘中与收盘观测，并保留逐行日期、币种、来源和缺失/过期状态；A 股资金榜按一级行业比较。跨资产比较仅匹配真实共同日期，不补造历史，也不把相关性解释为可靠对冲或因果关系。
