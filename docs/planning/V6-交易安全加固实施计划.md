## 3. 已完成的交易与账务基础

- 未知 Account、Instrument、Binding、ContractSpecification 全部拒绝。
- Runtime 在 Gateway 副作用前原子抢占 Command。
- 单腿与双腿统一通过 TradeCommand。
- `result_unknown` 先查 Journal，再查 Venue，不重下。
- FinancialFact 不可变，Formal Position/PnL 可重建。
- PnL 分为 Trading、Funding、Swap、Fee、FX 和 Total。
- NAV 使用统一 valuationTime，并显式报告缺失账户。
- 外部与本地冲突形成 Reconciliation Difference。

## 5. Production Gate 5A/5B

已通过 PR `#23`：

- Live 环境只允许 Production Authentication。
- Bearer Token 只以 SHA-256 哈希配置。
- Role：viewer、researcher、trader、risk_officer、operations、admin。
- Permission 默认拒绝。
- actor/reviewer 绑定认证 Principal。
- trader/admin 申请，独立 risk_officer/admin 批准。
- admin 不能自批。
- Session 固定账户、策略、品种、方向、订单类型、时间和额度。
- Kill Switch、历史差异、不合格 EOD、重叠和超限阻断批准。
- SQLite `BEGIN IMMEDIATE` 防止并发穿透单日额度。

## 6. Production Gate 5C

当前 PR `#25` 已实现：

### Provider

```text
secret://environment/<name>
secret://windows-credential-manager/<name>
```

- 旧格式只做迁移兼容。
- Unknown Provider 不回退。
- Environment Provider 返回字段存在性和版本元数据。
- Windows Credential Manager Provider 非 Windows或依赖缺失时 fail-closed。
- `resolve` 只在 Runtime Gateway 内部调用。

### Rotation Metadata

```http
POST /api/v1/security/credential-rotations
GET  /api/v1/security/credential-rotations
```

只保存 Reference、Provider、Version、时间、操作人、原因和幂等哈希，不保存凭证内容。

### Redaction

Backend 与 Runtime 统一处理嵌套结构、敏感键、Bearer、私钥块、URL 认证信息和异常文本，替换为 `[REDACTED]`。

### 验收路径

- Runtime Provider 与 Redactor 金样本。
- Backend Rotation 与 Redactor 金样本。
- Repository Secret Scan。
- Backend、Runtime、Frontend 全量回归。
- 实施计划、技术合同、API Spec、Release Gate、README、START-HERE 和 Changelog 同步。
