## 4. Phase 4C：受控实盘接入

### 4C-1 只读实盘

- Bybit：Open/History Order、Execution、Position、Wallet、Transaction Log。
- MT5：Order、Deal、Position、AccountInfo。
- 缺少凭证、依赖、账户映射或 Terminal 时 fail-closed。
- 查询错误不得解释为空仓或零余额。

### 4C-2 影子核对

- 外部 Order、Fill/Deal、Position、Balance 继续进入 Phase 4B Reconciliation。
- Funding、Swap、Commission/Fee 通过 `/venue/economic-events` 导入 FinancialFact。
- 未映射 Instrument 的事件显式 skipped。
- 重复导入不重复改变 Formal PnL。

### 4C-3 受控写入

写入必须同时通过：

1. Platform `liveTradingEnabled`。
2. Platform Kill Switch 和 Execution Risk。
3. Runtime `environment=live`。
4. Runtime `liveWriteEnabled=true`；默认 false。
5. Account、StrategyInstance、Symbol allowlist。
6. 单笔最大名义金额。
7. 单日累计名义金额。
8. Command 和外部 client identity 幂等。
9. Credential Ref 完整且脱敏。

Bybit 使用确定性 `orderLinkId`；MT5 使用 Magic、Comment、Order/Deal/Position Ticket。同步 ACK 不视为成交。
