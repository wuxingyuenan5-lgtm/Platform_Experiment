## 1. 总目标

```text
交易输入可验证
+
命令、事实和处置幂等
+
结果未知可恢复
+
金融事实可重建
+
双腿风险可处置
+
真实 Venue 可查询
+
实盘写入可限制、可关闭、可追溯
+
日终差异、SLA 和扩大实盘门禁可审计
+
身份、权限和实盘批准可确认
+
代码、测试、文档和 CI 全程留痕
```

Bybit 与 MT5 采用真实账户接入，并优先使用小资金、最小允许仓位完成运营验收。但自动实盘写入默认关闭；真实账户存在和工程 CI 通过都不等于自动实盘获批。

## 4. Production Gate 5A：身份认证与 RBAC

当前 PR #23 已实现：

1. Live 环境只接受 `api_key` 认证模式。
2. Bearer Token 通过 SHA-256 哈希匹配；仓库和数据库不保存原始 Token。
3. 最小角色：viewer、researcher、trader、risk_officer、operations、admin。
4. Trading、Risk、Audit、Reconciliation、EOD 和 Live Session 权限默认拒绝。
5. 请求 Actor 必须匹配认证 Principal，不能由请求体冒充。
6. Live 匿名、无效凭证、停用凭证和 development auth 全部 fail-closed。
7. `/health` 保持为不含业务数据的公开探针。

## 5. Production Gate 5B：双人实盘会话

当前 PR #23 已实现：

1. trader/admin 申请会话，risk_officer/admin 批准。
2. Applicant 与 Approver 必须为不同 User ID；admin 也不能自批。
3. 会话固定 StrategyInstance、Account、Symbol、Side、Order Type、时间和额度。
4. Kill Switch、Open/Accepted Difference、重叠会话、绝对限额和不合格 EOD 阻断批准。
5. Live Command 在写入 Order 和调用 Runtime 前认领唯一 Approved Session。
6. Command ID 重放幂等，载荷冲突返回 409。
7. SQLite `BEGIN IMMEDIATE` 串行化并发额度认领，避免并发穿透单日限额。
8. 撤销和过期会话立即失效。

## 6. 真实账户运营验收

依赖真实账户、小资金和人工监督，不能由 CI 代替：

- [ ] Bybit 真实账户只读核对。
- [ ] MT5 真实账户只读核对。
- [ ] trader 申请最小仓位窗口，独立 risk_officer 批准。
- [ ] 使用最小允许仓位完成下单、撤单、成交、查询和事实导入。
- [ ] 每个测试日形成 EOD Report。
- [ ] 连续多个真实日终周期无未解释差异。
- [ ] Kill Switch、断网、Runtime 重启和 `result_unknown` 演练。
- [ ] 会话结束后 Write Gate、Notional Limit、临时 allowlist 和批准窗口强制复位。

运营验收前保持 Platform 与 Runtime 写开关关闭。即使通过，也只能进入独立扩大规模评审，不自动提高限额。

## 7. 下一批 Production Gate

### 5C：生产密钥托管

- 可替换 SecretProvider。
- Windows Credential Manager 或受控环境注入。
- 引用版本与轮换审计，不保存历史明文。
- API、日志、异常、AuditEvent 和测试快照统一脱敏。
- Repository Secret Scan 持续作为 CI 阻断项。

### 5D：监控、告警、备份与恢复

- Runtime、Venue、EOD、Difference、Kill Switch 和 Live Session 机器可读状态。
- 告警去重、确认、关闭和责任人。
- 受控调度只触发 EOD、备份和健康检查，不开启交易或接受差异。
- Platform DB、Runtime Journal 和配置清单一致性备份。
- 新目录恢复演练；恢复后 Live Gate 与 Kill Switch 默认安全关闭。

## 8. 当前明确限制

- 真实凭证和账户配置未提交仓库，也不得提交。
- CI 不接触真实账户，无法替代运营验收。
- WebSocket 持续状态流尚未替代主动查询。
- 生产 SecretProvider、告警、备份与恢复演练尚未完成。
- EOD Report 不自动修改真实仓位或解决差异。
- Production Gate 5A/5B 完成不自动开启 Live Write。
