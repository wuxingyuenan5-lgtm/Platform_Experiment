# 首页：模块定位

状态：`active`  
产品基线：Platform V5  
架构版本：Platform V6  
适用分支：`refactor/frontend-architecture-v6`  
文档层级：一级产品模块定位

## 1. 模块定位

首页是平台品牌入口、少量关键信息摘要和核心模块导航页。

它帮助用户理解平台定位、快速查看高优先级摘要并进入授权模块，不承担任何业务模块的完整工作流。

## 2. 核心用户

- 首次进入平台的用户。
- 日常需要快速跳转的用户。
- 需要查看少量平台摘要的研究、投资和管理人员。

## 3. 核心任务

用户进入首页后应能够：

1. 理解平台品牌和产品定位。
2. 查看少量跨资产或平台状态摘要。
3. 进入对冲基金看板。
4. 进入新闻日历与理财。
5. 进入策略。
6. 进入风险管理，具有权限时。
7. 进入金融AI分析。

## 4. 产品主责内容

首页主要负责：

- 品牌主视觉和正式文案。
- 一级模块入口配置。
- 少量市场摘要配置。
- 重要风险、数据、审批或消息摘要，适用时。
- 桌面端第一屏阅读顺序。

首页摘要通过 Backend Read Model 获取，不拥有原始行情、风险、账户、订单和任务事实。

## 5. 明确不负责

- 完整研究看板和工具目录。
- 新闻、事件和理财完整列表。
- 交易参数和正式交易操作。
- 策略损益、账户资金和订单管理。
- 风险规则、审批和风险处置。
- 金融AI分析完整任务工作流。
- 系统级管理主操作。

## 6. 与其他模块的关系

- 对冲基金看板提供研究入口和市场摘要来源。
- 新闻日历与理财提供事件和内容摘要来源。
- 策略提供分析、执行和策略管理入口。
- 风险管理提供必要风险、数据和待办摘要。
- 金融AI分析提供任务入口和少量状态摘要。

首页只展示摘要和跳转，不复制目标模块的完整对象和操作。

## 7. 数据与权限边界

- 入口根据页面访问能力和数据范围显示。
- 市场和状态摘要具有来源、数据时间和质量状态。
- 未授权账户、策略、订单、风险和审计详情不得出现在首页。
- 前端隐藏入口不能替代后端 Query 权限校验。

## 8. 产品文档边界

当前代码实现、静态数据位置、具体 Vue 文件和技术债务不在本定位文档中维护，应进入审计或实施盘点文档。

## 9. 验收标准

- 首页清楚表达平台定位。
- 用户可以进入所有授权一级模块。
- 风险管理入口的产品规则明确，不再无说明遗漏。
- 首页摘要不形成第二套业务事实。
- 页面不包含交易、风险处置和系统管理主操作。
- 正式模块名称统一使用“金融AI分析”。
