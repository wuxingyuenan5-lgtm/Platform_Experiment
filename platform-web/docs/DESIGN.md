# UI and Interaction

Platform Web 是专业金融工作台：信息密度可以高，但层级、风险和数据状态必须一眼可辨。视觉表现服务判断与操作，不用装饰掩盖数据缺失。

## 页面骨架

```text
Application Shell
  ├─ Global navigation
  └─ Module Shell
      ├─ Page title and primary action
      ├─ Filters and summary
      ├─ Main workspace
      └─ Secondary records / details
```

- 一个页面只有一个主要纵向滚动 Owner。
- 标题、筛选、摘要和主要操作在同类页面保持稳定位置。
- 固定底栏必须为正文预留空间；Overlay 有统一层级。
- 表格和图表在窄视口优先降列、换行或局部滚动，不裁掉关键风险字段。

## 视觉语言

- 沿用各模块现有主题变量；A 股看板保持平台的浅色蓝灰底、白色卡片与蓝色操作色。强调色表达选择、涨跌、警告和危险，不强制改为深色主题。
- 盈亏颜色必须同时配合符号、文字或图标，不能只靠红绿判断。
- 标题、正文、辅助信息和表格数值具有稳定字号层级。
- 对冲看板各市场侧边栏沿用 A 股标准：Aptos 与平台中文回退字体，导航 13px、分组按钮 11px、行高 1.5，当前项字重 600；字体由共用侧边栏组件固定，避免外层市场主题改变导航排版。
- 对冲看板各市场共用 `hedgeBoardTheme.less` 中的正文、蓝灰色、卡片与控件圆角、间距和阴影变量；顶部市场切换工具栏保留统一的浅红色选择态。页面布局与滚动恢复由 `ResearchWorkspace` 统一维护，A 股继续保留最近三个子页。
- 数字采用一致的小数、千分位、币种和单位规则；未知值显示 `—` 或明确状态，不显示伪造的 `0`。

## 数据状态

每个数据区块必须覆盖：loading、empty、unavailable、error、permission denied 和 stale。`sample` 数据在内部保持不可执行，用户界面使用简洁业务语言，不展示工程元数据。

## A 股行业与主题研究（2026-11-08）

A 股看板将原“主题与行业”“估值”“拥挤度”合并为“行业与主题研究”（`/hedge-board/a-share?view=themes`）。以按钮切换指数与风格、行业研究、主题研究三个工作区，默认进入行业研究。行业研究用可搜索的行业选择器联动指标；主题研究恢复强弱矩阵和左侧主线导航，支持排序、主线及卫星主题切换；同一时刻只显示当前工作区，已访问视角保留筛选与图表状态。

行业选择统一联动估值、景气、成交/换手、参与度和关联主题；行业内直接并列显示估值/参与度、六项景气的本期/上期/变化与各自财报期，并展示一份量能曲线和一处关联主题。分位热力图、相对区间散点及历史、主题成员、全行业对照按需展开；主题成员按有效申万一级分类关联并按股票代码去重，原二级行业标签不改。主题研究将画像、成交与价格、相关行业直接联动显示，主线排行和产业链/成员走势直接展示，参考 ETF 可展开，保留相关主题与行业跳转。指数与风格展示“大盘估值”“广度与拥挤度”两个子页。大盘估值在指数估值走势下方展示巴菲特指标，底部展示股债性价比。全 A 景气走势与行业横向对照置于行业研究的景气指标之后。行业量能比较仅保留在行业研究，全市场分项与模型不再重复行业比较。独有内容和交互均保留，不将行业整体指标当作主题指标。

旧 `view=valuation` 和 `view=crowding` 查询参数继续保留；估值进入指数与风格，带主题的拥挤度链接进入该主题的综合研究（其中直接展示成交与价格），不带主题则进入广度与拥挤度。`section=industries|themes|indices` 对应当前工作区，旧 `section=market` 打开广度与拥挤度；`industry` 持有行业代码，`theme` 持有主题，旧 `themeView=overview|activity` 不再拆分内容。各指标保留自己的来源、日期、样本和缺失状态，刷新复用原只读接口与已有本地分类，不新增采集或财务指标计算。布局按 Owner 要求在 4373 验收；浏览器身份使用隔离测试响应，研究数据来自本地 API。内容删改继续待 Owner 审阅决定。

## 跨所价差行情分析 Demo（2026-11-06）

交易平台 → 跨所价差新增独立“行情分析 · 新版”，地址为 `/strategy/platform?desk=crossSpread&section=analysisDemo`；原行情分析与执行页保留。新版仅使用确定性合成行情和本地计算，无后端、数据库、账户接入或执行交接。所有金额和图表明确属于演示数据，合并与旧页删除待 Owner 决定。

研究分为价差与净空间、统计分析、回归与时段、兑现与持有、来源与失效条件。中间价差只作研究；多空报价按 A/B 方向分别估算净空间，点差不重复扣除，资金费和库存费按假设事件时点计数。F−C 沿用直接价差、平价 U/oz 假设；名义价、佣金、未来点差及费率均为可见算例假设，不表示账户规格或真实市场预期。

统计分析随 7/30/90 日研究窗口、买/卖/中间价差、时段与单位联动，包含分布与经验累计分布、九档分位和尾部形态、水平及连续变化标准差、滚动中枢、滞后相关、AR(1) 半衰期、星期 × 小时热图、日/周/月分组及样本 CSV。bps 使用可见的 4,000 基准；不以价差为分母计算收益率或年化波动。连续变化、滚动窗口与滞后配对不跨缺口，样本不足保留空值；半衰期只作线性拟合描述，不表示已通过平稳性检验。顶部情景只改当前快照，不改写历史。

回归研究以早期 60% 样本估计分时段中枢及 MAD，后续 40% 冻结阈值；独立偏离事件保留 24h 超时及休市/缺口/末端未完整观察，路径到达率不称为净收益胜率。补充固定期限有利变化、MAE/MFE、方向对比和“先修复/先触及风险线/期限内均未到达/路径缺失”分类；已知先到结果不被后续缺口抹去。CFD 休市停止当前机会估计，代币重估停止旧中枢的修复测算。

兑现与持有包含报价时差筛选、永续合成盘口逐档吃盘、CFD 单边滑点预算、容量阶梯、修复幅度 × 持有时间净空间矩阵、两腿资金压力算例与休市重开跳变。数量滑点替换原额外损耗，往返不重复扣费；盘口不足不以部分成交均价代替全量价格。CFD 无可验证集中盘口，不伪造其深度。压力算例不是账户保证金或清算预测；休市前后直接比较，不填补中间价格。真实成交能力、领先滞后和长期统计显著性不从合成序列推断。

独立预览 `/cross-spread-demo.html` 复用同一 Vue 页面与图表。在 `platform-web` 运行 `node scripts/preview-cross-spread-demo.mjs`，将演示页构建到仓库 `.codex/previews/cross-spread-market-demo/site` 并在本机 `127.0.0.1:4375` 提供静态预览；不启动认证、采集或执行接口，不切换 4373 运行版。16 项公式/统计/事件边界测试、策略范围类型检查、构建与独立预览桌面/390px 交互检查通过。

## 资费行情分析 Demo（2026-11-06）

交易平台 → 资费新增独立「行情分析（新）」，地址为 `/strategy/platform?desk=funding&section=analysisDemo`。旧行情分析、执行页及跨所价差独立 Demo 保留；合并与删除待 Owner 决定。本页定位是研究指定持有期的同所现货多／永续空净收益和可实现性：机会观察池之后，分别展示资费与收益、基差与拥挤、容量与现金、产品与事件。持仓会计、下单、实际账户可用资金不进入本 Demo。

参考 [strategy-research 资费策略 v0.6.0](https://github.com/wuxingyuenan5-lgtm/strategy-research/blob/main/funding_rate/README.md)。所有价格、30 天结算序列、下一期假设、规则周期、手续费、盘口深度、状态标签与事件为确定性合成样例，截面固定为北京时间 2026-11-06 00:00；产品名称不证明已上市、已匹配或账户可交易。股票、金属的未核验映射不参与净收益排名，界面和 CSV 的经济结论保留待核验。Premium Index 与清算/撤单样本不由其他变量替造。

样例按 4h／8h 各自结算时点汇总过去 24h，未来按指定周期及持有天数计数；下一期情景不混入历史。未来资费按设定费率延续比例及固定结算价格测算，没有统计预测或置信区间。`q=N/S0`；中间价基差变化损益为 `−N×基差变化bp/10000`，净收益再扣四次交易费用和独立盘口成本，资本收益分母为现货投入加独立合约储备。使用可成交 VWAP 时应取消已含在成交价中的盘口成本。采用正确恒等式 `F−S=(F−I)−(S−I)`，不采用参考文档该处的加号；三项展示统一以现货价格归一化。

容量取 25bp 内较薄一腿的压力深度；演示盘口成本为 `2+8×N/压力容量` bp，不是实测 VWAP。现金需求含空头上涨损失、不利基差变化、假设 0.5%维持保证金与退出半程成本；现货浮盈和场外资金不当作可用保证金。0.5%基差风险预算、费用、深度和储备比例都是可审阅的情景假设，不是生产阈值。高净收益不能越过配对、退出深度和现金约束；正资费策略在延续比例为零或转负时保持暂缓。硬性平台事件只列核验问题，不因本页数值正常而视为已经通过。

## 高风险交互

- 交易、撤单、平仓、配平、权限与 Kill Switch 操作需要明确对象、方向、数量和后果。
- 主要风险提示与操作不能因响应式降级而消失。
- 提交中禁止重复操作；结果未知不能显示为失败后可直接重试。
- 所有确认弹窗只总结业务意图，不展示凭据、内部 payload 或调试信息。

## 响应式基线

- 支持约定桌面视口、浏览器缩放和系统缩放组合。
- 通过统一 Grid、Flex、最小宽度和容器规则适配，不逐页面堆分辨率补丁。
- 窄视口优先保留身份、状态、风险和主要操作，次要字段进入详情或明确的更多菜单。
