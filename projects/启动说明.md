主要模块：

## 一、推荐启动顺序

建议开 3 个终端，按顺序启动：

```text
1. 启动 MySQL 数据库
2. 启动 auth-service，默认端口 8080
3. 启动 data-service，默认端口 8082
4. 启动前端 admin-risk，默认端口 5173；如果 5173 被占用，Vite 会自动改用 5174 等端口
```

数据库初始化和表结构说明见：

```bash
/home/ymy/Variable-Global-wip/projects/数据库.md
```

## 二、启动前端

前端目录：

```bash
cd /home/ymy/Variable-Global-wip/admin-risk
```

首次启动或依赖缺失时安装依赖：

```bash
HUSKY=0 pnpm install
```

启动开发服务：

```bash
pnpm dev
```

启动成功后看终端输出，例如：

```text
Local:   http://localhost:5173/
Network: http://192.168.126.131:5173/
```

浏览器访问实际输出的地址即可。如果 5173 被占用，可能会显示 5174：

```text
http://127.0.0.1:5174/
```

注意：这个前端项目使用 pnpm workspace，不要用 `npm install`。如果看到下面错误：

```bash
npm error Unsupported URL Type "workspace:": workspace:*
```

说明用了 npm，改用：

```bash
HUSKY=0 pnpm install
pnpm dev
```

## 三、前端代理关系

前端开发服务通过 `admin-risk/vite.config.ts` 代理到本机后端：

```text
/login、/register、/me、/menus、/api/v1/users、/notifications、/risk  -> http://127.0.0.1:8080
/dataApi                                                              -> http://127.0.0.1:8082
```

所以前端、auth-service、data-service 在同一台设备上运行时，正常只需要保证：

```text
auth-service 监听 8080
data-service 监听 8082
前端使用 pnpm dev 启动
```

## 六、Bybit 账户和 API Key

当前主要支持 Bybit 统一账户。

在前端新增账户时需要填写：

```text
账户名称：自定义展示名称，例如 ymy bybit test
账户类型：Bybit
账户地址：自定义唯一标识，例如 bybit-ymy
初始资金：用于计算单位净值，例如 10
API Key：Bybit 后台创建的 API Key
API Secret：Bybit 后台创建的 API Secret
```

API Key 和 Secret 会由 data-service 使用 `ACCOUNT_ENCRYPTION_KEY` 加密后保存到数据库，不会明文返回给前端。

也可以通过环境变量临时配置默认 Bybit 凭据：

```bash
cd /home/ymy/Variable-Global-wip/projects/risk-control/data-service
export BYBIT_API_KEY="你的key"
export BYBIT_API_SECRET="你的secret"
./start.sh
```

## 七、同步账户和净值统计的区别

前端“同步账户”按钮只用于更新当前资产数值：

```text
写入 assets.snapshot_kind = current
用于刷新账户表、总资产、可用资金等当前值
不会生成走势图上的净值点
```

账户净值统计由 data-service 定时任务生成：

```text
每 5 分钟边界运行，例如 09:00、09:05、09:10
写入 assets.snapshot_kind = valuation
走势图只读取 valuation 数据
```

走势图支持：

```text
过去一天：5 分钟采样
过去一周：30 分钟采样
过去一月：约 2 小时采样
```

## 八、注册和登录流程

注册入口在登录页：

```text
没有账号？提交注册申请
```

注册申请可选身份：

```text
访客 guest
员工 employee
管理员 admin
```

注册后不能立即登录，需要管理员审核通过。管理员登录后在“用户/注册申请”相关页面审核，通过后该用户才能登录。

不同角色前端显示不同：

```text
访客：偏只读
员工：可同步数据、可新增账户
管理员：可审核注册、管理用户、删除账户
```

## 九、常用排查命令

查看前端端口：

```bash
ss -ltnp | grep -E '5173|5174|vite'
```

查看 auth-service：

```bash
ss -ltnp 'sport = :8080'
```

查看 data-service：

```bash
ss -ltnp 'sport = :8082'
```

查看相关进程：

```bash
ps -ef | grep -E 'vite|pnpm|auth-service|data-service' | grep -v grep
```

查看 data-service 健康检查：

```bash
curl http://127.0.0.1:8082/health
```

查看 auth-service 是否响应：

```bash
curl http://127.0.0.1:8080/menus
```

如果端口被占用，先查 PID：

```bash
ss -ltnp 'sport = :8082'
```

看到 `pid=xxxx` 后停止：

```bash
kill xxxx
```

如果仍不退出：

```bash
kill -9 xxxx
```

注意：停止前台服务用 `Ctrl + C`。不要用 `Ctrl + Z`，它只是暂停进程，不会释放端口。
