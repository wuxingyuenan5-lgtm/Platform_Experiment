# 私募交易风控平台完整技术文档（修订版）

## 一、项目概述

### 1.1 项目目标
- **核心监控对象**：Puridia实盘、MT5考试盘、Bybit现货/合约账号
- **核心功能**：账户资金监控、开单情况跟踪、风控规则校验、策略收益统计、净值曲线展示
- **扩展能力**：后续接入套利策略账户、多交易员统一监控
- **附加模块**：独立理财展示平台（人民币汇率+U价实时行情）
- **UI风格**：偏蓝色极简科技风，深色+双浅色主题，参考antigravity.google


## 二、用户角色与权限体系设计

### 2.1 用户角色定义

基于需求分析，系统需要支持三种用户角色：

#### 1. 游客（Guest）
- **访问权限**：只读权限
- **可访问功能**：
  - 查看仪表盘总览数据
  - 查看产品管理页面（Alpha+、抄底策略、交易员详情）
  - 查看理财展示页面
  - 查看公开的净值曲线和收益数据
- **限制功能**：
  - 无法进行任何编辑操作
  - 无法查看风控告警信息
  - 无法访问账户管理功能

#### 2. 员工（Employee）
- **访问权限**：基础操作权限
- **可访问功能**：
  - 所有游客功能
  - 查看详细的成交记录
  - 查看风控记录（只读）
  - 查看账户详细信息
  - 查看个人负责的策略数据
- **限制功能**：
  - 无法修改风控规则
  - 无法添加/删除账户
  - 无法修改系统配置
  - 无法查看其他员工的私有数据

#### 3. 管理员（Admin）
- **访问权限**：完全权限
- **可访问功能**：
  - 所有员工功能
  - 配置和修改风控规则
  - 添加/编辑/删除账户
  - 绑定交易员与模拟盘账号
  - 查看所有账户和策略数据
  - 接收实时风控告警推送
  - 下单操作触发提醒通知
  - 系统配置管理

### 2.2 权限控制矩阵

| 功能模块 | 游客 | 员工 | 管理员 |
|---------|------|------|--------|
| 仪表盘总览 | ✅ | ✅ | ✅ |
| 产品详情查看 | ✅ | ✅ | ✅ |
| 成交记录查看 | ❌ | ✅ | ✅ |
| 风控记录查看 | ❌ | ✅（只读） | ✅（读写） |
| 账户管理 | ❌ | ❌ | ✅ |
| 风控规则配置 | ❌ | ❌ | ✅ |
| 实时告警接收 | ❌ | ❌ | ✅ |
| 理财页面 | ✅ | ✅ | ✅ |
| 系统配置 | ❌ | ❌ | ✅ |

### 2.3 权限实现方案

#### 前端权限控制
- **路由级权限**：通过Vue Router守卫控制页面访问
- **组件级权限**：使用自定义指令`v-permission`控制按钮和功能显示
- **数据级权限**：根据用户角色过滤显示的数据范围

#### 后端权限控制
- **接口级鉴权**：每个API接口验证用户角色和权限
- **数据级隔离**：员工只能访问自己负责的数据
- **操作日志**：记录所有敏感操作，便于审计

### 3.1 整体架构
```
┌─────────────────┐    ┌─────────────────┐
│   前端应用       │    │   后端服务       │
│  Vue3 + TS      │◄──►│  API Gateway    │

                                │
        ┌───────────────────────┼───────────────────────┐
        │                       │                       │
┌───────▼───────┐     ┌─────────▼─────────┐   ┌─────────▼─────────┐
│   MySQL 8.0   │     │     Redis 6.0     │   │  第三方API         │
│  账户数据      │     │  缓存/实时指标     │   │  Puridia/MT5/Bybit │
```

### 3.2 模块划分

#### 后端服务模块
1. **认证服务（Auth Service）**：用户登录、JWT生成、权限验证
2. **数据中心服务（Data Service）**：第三方API对接、数据采集清洗
3. **风控引擎服务（Risk Service）**：风控规则管理、实时校验、告警推送
4. **账户管理服务（Account Service）**：账户CRUD、绑定、份额计算
5. **定时任务服务（Scheduler Service）**：数据同步、任务调度
6. **理财数据服务（Finance Service）**：理财活动数据拉取

#### 前端功能模块
1. **认证模块**：登录/登出、用户信息管理
2. **仪表盘模块**：首页总览、策略卡片、净值曲线
3. **产品管理模块**：Alpha+、抄底策略、交易员详情
4. **风控管理模块**：规则配置、记录查询、实时告警
5. **账户管理模块**：账户列表、新增编辑、份额统计
6. **理财展示模块**：理财活动展示、汇率显示
7. **公共组件模块**：UI组件、工具函数、状态管理

#### 6.1.2 登录API流程
1. 前端发送用户名和密码到`/api/auth/login`
2. 后端验证用户凭证
3. 验证成功：生成JWT Token，设置过期时间（24小时）
4. 返回Token和用户基本信息（包括角色、权限）
5. 前端存储Token到localStorage
6. 跳转到仪表盘页面

### 6.2 权限控制实现

#### 6.2.1 路由守卫
```javascript
// 路由守卫逻辑
router.beforeEach((to, from, next) => {
  const token = localStorage.getItem('token');
  const userRole = store.getters.userRole;
  
  // 公开路由直接通过
  if (to.meta.public) {
    next();
    return;
  }
  
  // 未登录重定向到登录页
  if (!token) {
    next('/login');
    return;
  }
  
  // 角色权限检查
  if (to.meta.roles && !to.meta.roles.includes(user_role)) {
    ElMessage.warning('无权限访问此页面');
    next('/dashboard');
    return;
  }
  
  next();
});
```

#### 6.2.2 组件级权限指令
```javascript
// v-permission指令
app.directive('permission', {
  mounted(el, binding) {
    const { value } = binding;
    const userPermissions = store.getters.userPermissions;
    
    if (value && !userPermissions.includes(value)) {
      el.style.display = 'none';
    }
  }
});

// 使用示例
```

## 七、部署与安全方案

### 7.1 部署架构
- **生产环境**：Linux服务器（CentOS 7+）
- **数据库**：MySQL 8.0主从复制 + Redis 6.0集群
- **Web服务器**：Nginx反向代理
- **域名配置**：风控平台和理财平台两个二级域名
- **SSL证书**：Let's Encrypt免费证书

### 7.2 安全措施
- **数据加密**：敏感数据AES加密存储
- **API安全**：JWT Token + 接口签名
- **访问控制**：IP白名单 + 防火墙规则
- **防爬虫**：验证码 + 请求频率限制
- **代码保护**：前端代码混淆 + 后端二进制加密
- **审计日志**：所有敏感操作记录日志

### 7.3 防抄袭措施
- **UI差异化**：完全自研界面，仅参考色彩风格
- **代码混淆**：JavaScript代码压缩混淆
- **接口保护**：域名白名单 + 请求签名
- **版权保护**：页面隐形水印 + 代码版权声明
