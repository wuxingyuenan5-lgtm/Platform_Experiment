# 私募交易风控平台分阶段后端开发方案（调整版）

## 一、项目拆分策略

### 1.1 调整后的开发优先级
根据您的反馈，重新调整开发顺序：

| 项目名称 | 项目代号 | 优先级 | 核心功能 | 预计开发周期 |
|---------|----------|--------|----------|--------------|
| 用户认证服务 | `auth-service` | 🔴 最高 | 用户登录、权限管理、角色控制 | 3-5天 |
| 数据监控服务 | `data-service` | 🟡 中等 | 账户数据采集、基础展示、API对接 | 1-2周 |
| 理财展示服务 | `finance-service` | 🟢 较低 | 理财数据、汇率展示、公开访问 | 2-3天 |
| 风控引擎服务 | `risk-service` | 🔵 最低 | 风控规则、告警推送、日志记录 | 1-2周 |

### 1.2 调整理由
- **用户认证先行**：确保后续所有服务都有统一的认证和权限体系
- **数据服务第二**：核心业务功能，依赖认证服务
- **理财服务第三**：相对独立，可快速实现
- **风控服务最后**：依赖前三个服务的数据和用户体系

#### 2.5.3 认证中间件（供其他服务使用）
```go
// auth_middleware.go - 可被其他服务导入使用
func AuthMiddleware() gin.HandlerFunc {
    return func(c *gin.Context) {
        token := extractToken(c)
        if token == "" {
            c.AbortWithStatusJSON(401, ErrorResponse("Unauthorized"))
            return
        }
        
        claims, err := validateToken(token)
        if err != nil {
            c.AbortWithStatusJSON(401, ErrorResponse("Invalid token"))
            return
        }
        
        // 将用户信息存入上下文
        ctx := context.WithValue(c.Request.Context(), "user_id", claims.UserID)
        ctx = context.WithValue(ctx, "role", claims.Role)
        c.Request = c.Request.WithContext(ctx)
        
        c.Next()
    }
}
```

#### 3.5.1 认证中间件集成
```go
// main.go - 导入auth-service中间件
import (
    "github.com/your-org/auth-service/internal/middleware"
)

func main() {
    r := gin.Default()
    
    // 公开路由（游客可访问）
    public := r.Group("/api/v1")
    public.GET("/data/total", handlers.GetTotalData)
    public.GET("/data/strategy/:name", handlers.GetStrategyData)
    
    // 认证路由
    authenticated := r.Group("/api/v1")
    authenticated.Use(middleware.AuthMiddleware()) // 复用auth-service中间件
    authenticated.GET("/accounts", handlers.GetAccountList)
    authenticated.POST("/accounts", handlers.CreateAccount)
    authenticated.POST("/data/sync", handlers.TriggerSync)
    
    r.Run(":8082")
}
```

### 4.5 与认证服务的轻量集成
虽然理财服务是公开的，但仍需要简单的角色验证：
```go
// 支持游客访问
func FinanceMiddleware() gin.HandlerFunc {
    return func(c *gin.Context) {
        // 尝试认证，但不强制
        token := extractToken(c)
        if token != "" {
            // 如果有Token，验证并设置用户信息
            claims, err := validateToken(token)
            if err == nil {
                ctx := context.WithValue(c.Request.Context(), "user_id", claims.UserID)
                ctx = context.WithValue(ctx, "role", claims.Role)
                c.Request = c.Request.WithContext(ctx)
            }
        }
        // 无论是否有有效Token都继续执行（公开访问）
        c.Next()
    }
}
```

1. **auth-service独立测试**：确保认证功能正常
