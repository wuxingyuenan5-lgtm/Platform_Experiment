# 参考资料区

这里放“对项目有帮助，但不是当前正式运行链路”的材料。

## 放什么

| 子目录 | 内容 |
|---|---|
| `example-code/` | 小型外部代码片段或索引，不放大型外部仓库 |
| `database/` | SQL schema、库结构、历史数据库草稿 |
| `screenshots/` | 页面截图、竞品截图、视觉参考 |
| `research/` | 市场研究、行业资料、技术调研 |

## 当前状态

- `schema.sql`、`库结构.sql`、`risk_control.sql`已归档到`references/database/`；
- 大型外部参考代码已移出项目根目录，具体位置由操作者本地工作区配置维护，不写入共享仓库；
- `platform-web/docs/trading-tools-bookmarks-review.md`仍由前端同步脚本读取，暂不移动。

## 规则

- 参考资料不能直接成为正式运行代码的隐式依赖；
- 正式代码确需读取参考区文件时，必须在脚本、架构文档和测试中显式声明；
- 如果某份参考代码被吸收进正式实现，要在任务文档中说明来源、许可证和取舍；
- 不批量删除旧资料；先移动、索引、验证，再考虑归档；
- 不记录个人主目录、用户名、凭据、内部远端地址或其他工作站绑定信息。
