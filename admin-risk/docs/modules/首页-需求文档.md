## 1. 文档定位

本文定义首页的用户任务、产品范围、信息架构、入口规则、摘要规则、权限、数据、状态、异常、交互、非功能要求和验收标准。

首页是平台品牌入口、少量关键摘要和核心模块导航页，不承担任何业务模块的完整工作流。

首页可以聚合其他模块的授权摘要，但：

- 不拥有原始行情、新闻、策略、订单、账户、风险、审计或 AI 任务事实。
- 不提供正式交易、审批、风险处置、数据修正和系统管理主操作。
- 不建立第二套经营驾驶舱、研究看板或策略管理工作台。

## 2. 产品目标

首页应帮助用户：

1. 快速理解平台定位和主要能力。
2. 识别当前可访问的一级模块。
3. 查看少量高优先级市场与业务状态摘要。
4. 判断是否存在需要立即关注的数据、风险、审批、服务或消息状态。
5. 使用稳定入口进入目标模块继续完整工作流。
6. 在部分数据源不可用时仍能完成基本导航。

首页的成功标准不是展示尽可能多的数据，而是：

> 用最少的信息帮助用户明确“平台是什么、当前最值得关注什么、下一步去哪里”。

## 3. 目标用户、权限和数据范围

### 3.1 目标用户

- 首次进入平台的授权用户。
- 日常需要快速跳转的研究、投资和交易人员。
- 策略负责人和管理观察人员。
- 风险、运营和数据核对人员。
- 仅具有部分模块读取权限的只读用户。

### 3.2 基础访问能力

候选能力：

- `home.read`：访问首页。
- `home.marketSummary.read`：读取市场摘要。
- `home.attentionSummary.read`：读取授权关注事项摘要。
- `home.platformStatus.read`：读取平台公开运行状态摘要。

一级模块入口仍分别判断对应模块的页面访问能力，不因具有 `home.read` 自动获得其他模块权限。

### 3.3 权限规则

首页必须分别判断：

- 是否允许进入首页。
- 是否允许看到某个一级模块入口。
- 是否允许读取某类摘要。
- 是否允许看到摘要中的数量、名称、金额、账户或策略范围。
- 是否允许跳转到摘要指向的目标页面。

规则：

- 无权限模块可以隐藏或显示禁用入口，具体表现由产品配置确定。
- 显示禁用入口时，只说明缺少访问权限，不泄露模块内敏感信息。
- 摘要数量也可能构成敏感信息，必须受数据范围约束。
- 前端入口隐藏不替代目标 Query 和目标页面的后端权限校验。

## 4. 核心用户问题

首页必须能够回答：

1. 这个平台主要用来做什么？
2. 我可以访问哪些一级模块？
3. 当前主要市场是否存在值得关注的显著变化？
4. 是否有重要风险、数据异常、服务异常、审批或人工任务？
5. 当前展示的数据是什么时间、来自哪里、是否可靠？
6. 我应该进入哪个模块继续处理？

首页不负责回答：

- 某个资产为什么上涨或下跌。
- 某个策略是否应该开仓。
- 某个订单为何没有成交。
- 某个风险事件应该如何处置。
- 某项损益的完整归因。

上述问题应进入对应业务模块处理。

## 5. 产品范围

### 5.1 必须包含

1. 品牌主视觉与平台定位。
2. 授权一级模块入口。
3. 少量跨资产或跨模块摘要。
4. 重要关注事项摘要。
5. 数据更新时间和质量表达。
6. 区块级加载、空数据、错误和降级状态。
7. 稳定的跨模块跳转。

### 5.2 可以配置包含

- 平台版本或环境标识。
- 用户欢迎信息。
- 最近访问模块。
- 高优先级公告。
- 少量平台运行状态。
- 金融AI分析任务入口或授权任务状态摘要。

这些内容不得挤占核心导航和关键信息位置。

### 5.3 明确不包含

- 完整研究图表和指标工作台。
- 新闻、宏观日历和理财完整列表。
- 正式交易参数、下单、撤单和补对冲。
- 策略损益、账户资金和订单管理完整视图。
- 风险规则配置、风险覆盖和处置主操作。
- 审批决定、数据修正和用户授权操作。
- 金融AI分析完整任务工作流。
- 系统设置和 Gateway 管理主操作。
- 第二套全平台搜索、报表或消息中心。

## 6. 信息架构

首页按以下阅读顺序组织：

1. 品牌主视觉与正式平台定位。
2. 一级模块快捷入口。
3. 高价值市场摘要。
4. 重要关注事项。
5. 辅助状态、公告或版本信息，适用时。

### 6.1 首屏优先级

首屏应优先保证：

- 平台身份可识别。
- 主要模块入口可识别。
- 高优先级异常可识别。
- 不依赖纵向滚动即可完成主要导航。

市场摘要数量和卡片尺寸应受到限制，不能因为数据源增加持续扩张首页。

### 6.2 区块独立性

各区块独立加载和降级：

- 品牌区不依赖外部数据。
- 模块入口不依赖市场数据。
- 某个摘要源失败不影响其他摘要。
- 关注事项失败不阻止用户进入其他模块。

## 7. 路由和上下文

### 7.1 首页路由

首页使用稳定一级路由，例如：

```text
/
或
/home
```

具体路径以正式前端路由配置为准，但全平台只保留一个正式首页入口。

### 7.2 可进入 URL 的上下文

首页原则上不需要复杂业务上下文。可以进入 URL 的参数仅限：

- 安全来源标记，适用时。
- 非敏感公告或引导状态，适用时。

不得通过 URL 传递：

- 账户 ID。
- 订单 ID。
- 审批内容。
- 风险处置参数。
- 交易模式切换参数。
- Live 交易许可。
- 敏感筛选条件。

### 7.3 跨模块跳转

首页跳转只传递：

- 目标模块或目标稳定路由。
- 安全、可验证的只读筛选条件，适用时。
- 来源标记，适用时。

目标模块必须重新执行权威 Query，不接收首页缓存对象作为正式事实。

## 8. 品牌主视觉与平台定位

### 8.1 必须表达

- 平台正式名称或品牌标识。
- 平台核心定位。
- 简洁、稳定、可长期使用的正式文案。
- 进入核心业务的明确视觉路径。

### 8.2 文案要求

- 不长期使用概念占位文案。
- 不使用无法验证的收益、能力或安全承诺。
- 不暗示 AI、自动策略或风险系统已经具备未实际实现的能力。
- 不使用容易让用户误认为正在实盘交易的动态效果或措辞。

### 8.3 视觉要求

首页可以使用品牌动画和“全球变量、蝴蝶效应”等视觉概念，但必须：

- 不遮挡模块入口和关键摘要。
- 不造成明显性能下降。
- 支持减少动态效果的系统偏好或降级方案。
- 在低性能设备或动画失败时保持可用。

## 9. 一级模块入口

### 9.1 固定模块

首页可配置展示：

- 对冲基金看板。
- 新闻日历与理财。
- 策略。
- 风险管理。
- 金融AI分析。

首页本身不重复设置“首页入口”。

### 9.2 入口字段

每个入口至少包含：

- 正式模块名称。
- 简短定位说明。
- 稳定路由。
- 图标或视觉标识。
- 权限状态。
- 可选的状态摘要或徽标。

### 9.3 入口规则

- 名称以治理术语表为准。
- 顺序以一级产品架构为准。
- 不因新增普通页面自动增加首页入口。
- 入口配置必须存在唯一维护来源。
- 模块入口中的徽标只展示摘要，不形成第二套消息或风险状态。
- 目标模块不可用时，应说明“服务不可用”“无权限”或“功能未开放”，不能统一显示为未知错误。

## 10. 市场摘要

### 10.1 定位

市场摘要用于提供少量高价值背景，不替代对冲基金看板和策略行情分析。

### 10.2 候选内容

根据正式配置选择少量指标，例如：

- 主要资产价格和区间变化。
- 风险偏好指标。
- 关键利率或美元指数摘要。
- BTC、黄金、主要股票指数摘要。
- 其他已经确认的高优先级跨资产变量。

首页不保证展示所有资产类别，也不形成用户自定义研究工作台。

### 10.3 摘要字段

每项摘要至少表达：

- `metricId` 或稳定指标标识。
- 指标名称。
- 当前值。
- 单位和计价币种，适用时。
- 变化值和变化方向。
- 比较基准和区间。
- `sourceTime` 或业务时间。
- `receivedAt`，适用时。
- 数据来源或来源类型。
- `DataQualityStatus`。
- `isEstimated`，适用时。
- 目标模块和安全跳转条件，适用时。

### 10.4 数据规则

- 行情类摘要来自 Execution Market Data 或对应聚合查询。
- 研究类摘要来自 Research Data。
- 首页 Read Model 只组合展示，不拥有事实。
- 不同时间、来源或口径的数据不得在无提示情况下直接比较。
- 缺失值不得显示为零。
- 估算值不得与正式值使用完全相同的视觉表达。
- 数据失效时保留最近值必须同时展示失效状态和时间。

## 11. 重要关注事项

### 11.1 可展示类型

首页可以展示有限的授权摘要：

- 阻断级或高优先级风险事件数量。
- Gateway、Runtime、数据源或关键服务不可用数量。
- 数据质量异常数量。
- 待处理审批数量。
- 待人工确认或对账差异数量。
- 高优先级未读消息数量。
- 金融AI分析任务失败或待查看结果数量，适用时。

### 11.2 摘要字段

每项关注事项至少包含：

- `attentionType`。
- 严重级别。
- 授权范围内的数量或状态。
- 数据截止时间。
- 来源模块。
- 目标路由。
- 是否存在立即阻断影响，适用时。

### 11.3 规则

- 首页只展示摘要和跳转。
- 不在首页审批、确认差异、覆盖风险或修正数据。
- 无权限用户不得看到敏感名称、账户、策略、金额和事件详情。
- 数量为零时可以隐藏、弱化或显示正常状态，产品表现需一致。
- 多个来源失败时分别展示局部状态，不将全部异常合并为模糊“系统异常”。

## 12. 辅助信息

可配置展示：

- 当前应用版本。
- DeploymentEnvironment。
- 全局公告。
- 数据更新时间摘要。
- 用户最近访问入口。

规则：

- Production 环境不等于 Live 交易模式，首页不得混淆两者。
- 首页不提供 TradingMode 修改入口。
- 版本和环境信息不得暴露内部主机、凭证和敏感部署细节。

## 13. Query、Command 和 Event

### 13.1 Query

首页候选 Query：

- `HomeOverviewQuery`：一次返回页面级版本、生成时间和区块状态。
- `HomeModuleEntrancesQuery`：返回授权模块入口与可用状态。
- `HomeMarketSummaryQuery`：返回配置范围内的市场摘要。
- `HomeAttentionSummaryQuery`：返回授权关注事项摘要。
- `HomePlatformNoticeQuery`：返回公告或版本信息，适用时。

Query 必须返回：

- 数据版本。
- 生成时间。
- 来源模块。
- 数据质量或区块状态。
- 权限过滤后的结果。

### 13.2 Command

首页默认不提供业务 Command。

以下操作不属于首页：

- 提交 TradeCommand。
- 审批或拒绝 ApprovalRequest。
- 确认 ReconciliationDifference。
- 修改 RiskRule。
- 修改用户权限。
- 修改 Gateway 或 Runtime。

简单的“记录最近访问”“关闭公告”等个人偏好行为，可以使用前端本地状态或独立用户偏好 Command，但不得与正式业务命令混合。

### 13.3 Event

首页可以订阅或消费摘要级事件，例如：

- 关键服务健康变化。
- 高优先级风险摘要变化。
- 数据质量摘要变化。
- 待办数量变化。

规则：

- 实时事件只用于及时刷新。
- 页面重连后必须重新执行 Query。
- 不依赖事件补齐全部首页状态。
- 首页不直接订阅外部交易所、MT5、vn.py EventEngine 或 Gateway 原始事件。

## 14. 状态与交互

### 14.1 页面级状态

必须区分：

- Initial Loading。
- Ready。
- Partial。
- Degraded。
- Page Error。

### 14.2 区块级状态

每个动态区块至少支持：

- Loading。
- Refreshing。
- Ready。
- Empty。
- Stale。
- Partial。
- Permission Denied。
- Error。

### 14.3 交互规则

- 首次加载可以使用骨架屏，但不得长期显示虚构数值。
- Refreshing 时保留旧值必须显示刷新状态。
- Stale 时展示最近值、数据时间和失效提示。
- Partial 时明确哪些来源缺失。
- Error 时提供重试或目标模块跳转，适用时。
- 页面刷新后不依赖大量浏览器本地业务状态恢复。
- 外部链接必须明确标识新窗口和目标站点。

## 15. 异常与降级

### 15.1 单一摘要源失败

- 仅影响对应卡片或区块。
- 其他模块入口和摘要继续可用。
- 展示失败来源和最后成功时间，能够取得时。

### 15.2 首页聚合 Query 部分失败

- 返回成功区块和失败区块状态。
- 不因为一个依赖失败统一返回空白页面。
- 前端不得把缺失区块渲染为正常零值。

### 15.3 权限服务异常

- 不开放此前未确认的入口或敏感摘要。
- 可以保留基本品牌页面和安全导航。
- 写入和高风险操作本来就不属于首页。

### 15.4 实时连接异常

- 展示实时更新中断。
- 继续允许通过普通 Query 刷新。
- 恢复连接后重新拉取快照。

### 15.5 全局严重故障

首页可以展示平台级维护或降级通知，但：

- 不伪造各业务模块具体状态。
- 不替代正式事故和服务健康页面。
- 不暴露内部故障细节。

## 16. 跨模块关系

### 16.1 对冲基金看板

- 提供研究和市场摘要来源。
- 首页跳转时只传递安全资产类别或指标上下文。
- 完整图表、统计和研究工具留在看板。

### 16.2 新闻日历与理财

- 提供高优先级事件或内容摘要，适用时。
- 首页不复制完整新闻流和宏观日历。

### 16.3 策略

- 提供策略模块入口和必要的执行异常摘要，适用时。
- 首页不展示完整 StrategyInstance、Order、Fill 或 PnL 明细。

### 16.4 风险管理

- 提供风险、服务、审批、审计和消息摘要。
- 首页不维护风险规则和处置状态。

### 16.5 金融AI分析

- 提供任务入口和有限任务状态摘要，适用时。
- 首页不执行分析任务，也不展示未经授权的分析内容。

## 17. 前端要求

- 使用正式模块注册或导航配置生成入口。
- 市场摘要和关注事项使用稳定 View Model。
- 页面不得直接依赖外部 API 字段。
- 区块具有独立 Error Boundary。
- 动画、图表和背景效果不能阻止键盘或鼠标访问主要入口。
- 常用桌面分辨率下不出现页面级横向滚动。
- 组件不得自行推断权限、数据质量和风险严重级别。
- Mock 和真实 Query 必须使用同一业务语义，但 Mock 必须清晰标识。

## 18. 后端和数据依赖

首页依赖：

- IAM 或权限查询。
- 模块与路由配置。
- Backend Read Model。
- Market Data 摘要。
- Research Data 摘要。
- Risk、Approval、Reconciliation、Data Quality、Observability、Notification 等摘要 Query，适用时。

首页不要求各依赖模块已经建设完整后端；未建设能力必须显示为未开放、无数据或不配置，不能用虚构事实填充。

Backend Read Model：

- 可以聚合多个领域。
- 可以缓存和重建。
- 不接受业务写入。
- 不拥有原始业务事实。
- 必须保留来源、截止时间和质量状态。

## 19. 数据安全与隐私

- 首页不得展示完整交易凭证、密钥、密码、Token 或内部连接字符串。
- 默认不展示完整账号、用户敏感信息和未经授权的资金金额。
- 账户和用户标识按权限脱敏。
- 审计事件只展示授权摘要，不展示敏感请求正文。
- 外部链接不得携带敏感查询参数。
- 页面缓存不得长期保存敏感业务数据。

## 20. 非功能要求

### 20.1 性能

- 品牌与导航区应优先渲染，不等待全部动态摘要。
- 首页聚合 Query 应支持区块并行和局部超时。
- 重型研究计算、损益计算和 AI 任务不得在首页请求中同步执行。

### 20.2 可用性

- 单个依赖失败不导致首页整体不可用。
- 在市场数据、实时通道或关注事项服务异常时，模块导航仍可使用。
- 页面刷新和返回首页不依赖服务端会话中的临时页面状态。

### 20.3 可观测性

至少记录：

- 首页 Query 成功率和延迟。
- 各摘要来源失败率。
- 区块级超时。
- 权限拒绝，不记录敏感数据。
- 用户入口点击的匿名或授权分析数据，适用时。

### 20.4 可访问性

- 入口可通过键盘聚焦和激活。
- 颜色不是表达风险和状态的唯一方式。
- 动画支持减少动态效果。
- 状态提示具有可读文本。

## 21. 报表、导入和导出

首页不提供正式报表生成、业务数据导入和明细导出。

可以提供：

- 跳转正式报表模块。
- 跳转数据导入或对账页面。
- 复制非敏感摘要值，产品确认后。

不得从首页绕过目标模块的权限、审计和审批要求。

## 22. 验收标准

### 22.1 产品验收

- 首页清楚表达平台定位。
- 用户可以识别并进入全部授权一级模块。
- 首页不形成第二套研究、策略、风险或管理工作台。
- 风险管理和金融AI分析入口规则明确，不被无说明遗漏。
- 首页不存在正式交易、风险处置、审批决定和系统管理主操作。

### 22.2 权限验收

- 不同用户只看到授权入口和摘要。
- 摘要数量、名称和金额遵守数据范围。
- 禁用入口不泄露目标模块敏感信息。
- 直接访问目标路由仍执行目标模块后端权限校验。

### 22.3 数据验收

- 每项动态摘要具有名称、值、单位、时间、来源和质量状态。
- 缺失数据不显示为零。
- 估算值和正式值可区分。
- Stale 数据显示最后时间和失效状态。
- 首页 Read Model 不接受业务写入。

### 22.4 状态验收

- 页面和区块支持 Loading、Empty、Stale、Partial、Permission Denied 和 Error。
- 单个摘要失败不导致首页白屏。
- 实时断线后可以通过 Query 恢复。
- 页面刷新后入口和摘要可以重新获取。

### 22.5 交互验收

- 核心入口在首屏可识别。
- 跨模块跳转使用稳定路由和安全上下文。
- 外部链接明确标识。
- 动画关闭或失败不影响导航和内容阅读。
- 常用桌面分辨率下无页面级横向滚动。

## 23. 后续配置项

以下属于后续配置或设计确认，不改变本文产品边界：

- 正式首页路径。
- 模块入口卡片的最终排序和视觉形式。
- 市场摘要的具体指标数量和配置来源。
- 关注事项的严重级别阈值与显示数量。
- 无权限入口采用隐藏还是禁用展示。
- 是否展示最近访问、平台公告和版本信息。
- 品牌动画的正式实现和性能降级方案。
