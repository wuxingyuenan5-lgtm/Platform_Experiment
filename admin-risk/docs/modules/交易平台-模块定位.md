# 交易平台：模块定位

状态：`active`  
适用基线：Platform V5

## 1. 模块定位

交易平台是策略模块中的交易前分析与交易执行工作台，负责将策略机会判断、交易参数确认、双腿执行和即时反馈组织为完整的交易流程。

交易平台覆盖以下三类策略：

- 资费套利。
- 跨所价差。
- 海内外价差。

抄底、短线交易员 L 和短线交易员 W 不通过交易平台执行，由策略管理统一承接其结果统计和复盘。

## 2. 核心用户

- 负责观察策略机会的研究或交易人员。
- 负责确认交易参数和执行订单的操作人员。
- 负责检查成交、配平和异常暴露的策略负责人。

## 3. 核心任务

交易平台支持用户完成以下任务：

1. 选择策略、市场、标的和账户。
2. 判断当前是否存在可执行机会。
3. 评估价差、分位、成本、收益和风险。
4. 配置两条交易腿的方向、数量、价格和订单类型。
5. 提交开仓、平仓或调整指令。
6. 检查成交结果、配平状态和异常暴露。

## 4. 页面结构

交易平台固定分为行情分析和交易执行两个页面。

### 4.1 行情分析

行情分析用于回答：

- 当前是否存在交易机会。
- 机会处于何种历史位置。
- 预期收益是否覆盖交易成本和风险。
- 应选择哪些交易所、标的、合约或市场组合。

主要内容包括：

- 市场报价和关键指标。
- 价格、价差和联动图表。
- 历史分位和统计分析。
- 期限结构或市场结构。
- 多市场、多平台或多标的对比。
- 与当前策略执行直接相关的成本和风险信息。

行情分析不提供正式下单主操作，也不复制对冲基金看板的完整研究体系。

### 4.2 交易执行

交易执行用于回答：

- 当前是否满足执行条件。
- 两条交易腿应如何配置。
- 预计收益、成本和风险是多少。
- 订单是否成交、配平并符合当前限制。

主要内容包括：

- 执行前状态和适用限制。
- 开仓、平仓和方向选择。
- 账户、数量、价格和订单类型。
- 两条交易腿及其配平关系。
- 预计收益、成本和执行影响。
- 当前执行订单和持仓摘要。
- 成交反馈、异常提示和暴露状态。

## 5. 策略能力范围

| 策略 | 行情分析 | 交易执行 |
|---|---:|---:|
| 资费套利 | 有 | 有 |
| 跨所价差 | 有 | 有 |
| 海内外价差 | 有 | 有 |
| 抄底 | 无 | 无 |
| 短线交易员 L | 无 | 无 |
| 短线交易员 W | 无 | 无 |

## 6. 主责对象

交易平台主责以下操作上下文：

- 当前策略与市场选择。
- 当前分析条件和筛选参数。
- 当前交易参数和执行指令。
- 当前执行批次及两腿关系。
- 当前订单、成交和配平反馈。
- 执行视角下的持仓、资金和风险摘要。

订单、成交、持仓和账户属于跨模块业务对象。交易平台负责其当前执行视图，完整查询、统计和复盘由策略管理承接。

## 7. 职责边界

### 7.1 负责

- 与具体策略交易直接相关的机会分析。
- 交易参数配置与执行前确认。
- 双腿订单提交和配平。
- 当前执行批次的反馈与异常提示。
- 执行视角下的持仓、资金和风险信息。

### 7.2 不负责

- 抄底及短线交易策略的平台下单。
- 长期策略绩效评价和完整损益归因。
- 全生命周期订单、成交和执行档案。
- 账户主档和平台级资金管理。
- 完整宏观、行业和跨资产研究。
- 全局风险规则、用户权限和系统审计管理。

## 8. 模块关系

### 对冲基金看板

交易平台读取与具体策略相关的研究结果和市场数据，不复制完整研究看板。

### 策略管理

交易平台负责当前执行过程；策略管理负责实际结果的统计、查询、归档和复盘。

### 风险管理

交易平台读取当前适用的风险状态、基础限制和告警，并在执行前进行提示或限制。风险规则、阈值和处置标准由风险管理维护。

## 9. 验收标准

- 交易平台仅展示 `platform.enabled = true` 的三类策略。
- 每类策略均明确区分行情分析与交易执行。
- 行情分析不包含正式下单主操作。
- 交易执行包含完整的双腿参数、订单反馈和配平状态。
- 当前执行视图与长期统计、归档和复盘边界清晰。
- 交易平台不重复建设研究、绩效、账户和风险管理的完整功能。
