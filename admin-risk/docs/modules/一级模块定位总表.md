# 一级模块定位总表

状态：`active`  
适用基线：Platform V5

## 1. 文档目的

本文档汇总 V5 当前一级架构及其主责，不改变任何已确认的一级导航和路由结构。

## 2. 一级模块总表

| 一级模块 | 核心定位 | 主要内容 | 明确不负责 |
|---|---|---|---|
| 首页 | 品牌入口、摘要和导航 | 品牌主视觉、市场摘要、核心模块入口 | 完整研究、交易、风控和管理功能 |
| 策略 | 具体投资策略研究、执行、统计和复盘 | 交易平台、策略管理 | 全局研究、全局风控、系统管理 |
| 对冲基金看板 | 宏观、资产类别和跨市场研究及工具聚合 | 宏观、商品、加密、美股、A 股、全球、交易工具 | 正式下单、策略绩效和全局风险处置 |
| 新闻日历与理财 | 事件、新闻和理财机会信息整理 | 宏观日历、新闻整理、理财信息 | 完整研究、正式交易和绩效管理 |
| 风控管理 | 全平台风险事件、状态和处置跟踪 | 风控详情、用户管理入口、个人账号 | 完整账户、报表、审计和系统监控主功能 |
| 金融 AI 分析 | 研究辅助、信息归纳和情景推演 | 展示案例、未来分析任务和结果容器 | 原始数据维护、自动交易和风险处置 |
| 数据 | 数据资源和数据状态管理 | 数据源、同步、质量和可用状态 | 业务研究结论和系统整体监控 |
| 账户 | 业务账户和资金账户主档 | 账户信息、权益、币种、平台关联 | 策略绩效、用户身份和财务核算 |
| 财务 | 财务和经营口径的资金收支信息 | 财务概览、费用和收支 | 策略损益归因和交易保证金管理 |
| 报表 | 跨模块结果汇总和结构化输出 | 风控、策略、账户等报表 | 原始业务对象维护和风险处置 |
| 监控 | 系统和数据服务运行状态 | 服务健康、连接、运行异常 | 市场、策略和账户风险判断 |
| 审计 | 操作和配置变更追溯 | 用户、时间、模块、对象、变更和结果 | 风险事件、通知投递和系统健康 |
| 用户管理 | 用户身份、角色和状态管理 | 用户资料、角色和启停状态 | 交易账户和个人绩效 |
| 系统设置 | 平台级基础配置 | 基本配置和功能开关 | 策略参数和风险事件处置 |
| 消息通知 | 跨模块消息展示和阅读状态 | 消息、来源、时间、已读状态和跳转 | 风险事件本身、新闻和审计日志 |

### 3.2 策略管理

全部纳管策略：

- 资费套利。
- 跨所价差。
- 海内外价差。
- 抄底。
- 短线交易员 L。
- 短线交易员 W。

固定页面：

- 策略损益。
- 账户资金。
- 订单信息。

## 4. 模块主责原则

- 同一个业务对象只能有一个主负责模块。
- 其他模块可以展示摘要、引用状态或提供跳转。
- 摘要展示不代表拥有完整业务对象。
- 页面复用不改变业务归属。
- 隐藏菜单不改变模块职责。
- 当前一级架构不因代码整理而改名、合并或删除。

## 6. 当前 V5 需要治理的交叉区域

### 6.1 风控详情

当前混入账户、报表、通知、审计和监控内容。后续本地整理时应逐步保留摘要、移除完整副本，但不改变路由结构。

### 6.2 首页

当前包含设计概念说明和静态行情摘要。应保持入口属性，避免继续扩张为第二套业务总览。

### 6.3 对冲基金看板

当前大型入口文件承担过多图表、数据和交互逻辑。后续只做技术拆分，不改变栏目结构。

### 6.4 金融 AI 分析

当前是展示案例和占位壳，不能被视为已实现真实 AI 能力。
