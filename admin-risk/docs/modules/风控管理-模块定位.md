# 风控管理：模块定位

状态：`active`  
适用基线：Platform V5

## 1. 模块定位

风控管理是面向全平台风险识别、风险记录、风险状态汇总和风险处置跟踪的一级管理模块。

它负责回答“当前有哪些风险、严重程度如何、是否需要处理、风险来自哪个策略或账户”，不负责完整策略研究、正式下单、账户主档管理、报表发布或系统服务监控。

## 2. 当前固定页面

- 风控详情。
- 用户管理。
- 个人账号。

本次不改变当前路由结构，但需要明确其中不同页面的职责边界。

## 3. 核心用户

- 风险管理人员。
- 投资管理人员。
- 策略负责人。
- 具有管理权限的系统管理员。

## 4. 核心任务

用户进入风控管理后应能够：

1. 查看风险记录总数、待处理数量和高风险数量。
2. 按风险等级、状态、来源和时间查看风险事件。
3. 识别风险关联的策略、账户、持仓、订单或系统对象。
4. 查看风险事件处理状态和最新更新时间。
5. 进入必要的用户或个人账号页面。

## 5. 模块拥有的业务对象

- 风险规则结果。
- 风险事件。
- 风险等级。
- 风险状态。
- 风险来源。
- 风险处理记录。
- 风险关联对象。
- 风险处置结果。

本模块不拥有完整账户主档、完整报表、系统监控数据或审计日志。

## 6. 风控详情职责

风控详情应聚焦：

- 风险概览。
- 风险事件列表。
- 待处理和高风险状态。
- 风险事件与策略、账户、订单的关联。
- 风险处理状态。
- 必要的资金和持仓风险摘要。

可以展示摘要：

- 总资产和可用资金风险摘要。
- 账户风险状态。
- 未读风险通知数量。
- 相关服务是否可用的简单提示。

不得长期承载：

- 完整账户管理页面。
- 完整报表中心。
- 完整通知中心。
- 完整审计日志。
- 完整系统服务监控。

## 7. 用户管理与个人账号

### 7.1 用户管理

当前位于风控路由下，但其业务主责是用户身份和权限管理。

风控模块只需要读取：

- 用户身份。
- 用户角色。
- 用户与风险事件的关联。

不应在风控业务组件中直接实现完整用户管理逻辑。

### 7.2 个人账号

用于展示当前用户或个人风险相关账号信息。

需要与独立账户模块区分：

- 个人账号关注当前用户身份和个人视角。
- 账户模块关注业务账户、资金账户或交易账户主档。

## 8. 风险分类建议

前端统一风险分类至少包括：

- 策略风险。
- 账户资金风险。
- 持仓风险。
- 订单和执行风险。
- 市场风险。
- 平台或交易所风险。
- 数据和系统风险。
- 合规或权限风险。

当前阶段可以先使用统一分类和状态，不要求实现完整规则引擎。

## 9. 风险状态语义

建议统一：

- 待确认。
- 待处理。
- 处理中。
- 已解决。
- 已忽略。
- 已升级。

风险等级建议统一：

- 低。
- 中。
- 高。
- 严重。

页面不得同时混用英文和中文状态作为正式用户口径。

## 10. 与其他模块的关系

### 策略管理

策略管理提供损益、资金、持仓、订单和执行记录；风控管理对这些信息进行风险判断和事件管理。

### 交易平台

交易平台读取是否允许执行、限制和告警结果；风控管理不替代交易执行。

### 账户

账户模块拥有完整账户主档和资金状态；风控管理只展示风险相关摘要和事件。

### 报表

报表模块负责风险报表的生成、展示或导出；风控管理拥有风险事件和处理状态。

### 审计

审计模块记录操作和变更；风控管理可以引用相关审计记录，但不拥有完整审计日志。

### 监控

监控模块负责系统服务和数据服务运行状态；风控管理只接收与业务风险有关的服务异常摘要。

### 消息通知

通知模块负责消息投递和阅读状态；风控管理负责风险事件本身。

## 11. 当前 V5 实现状态

已实现：

- 风险记录、待处理、高风险等摘要指标。
- 风险事件表格。
- 资产和可用资金摘要。
- 用户角色和服务状态提示。
- 账户、报表、通知、审计和监控的局部展示。

当前主要技术债务：

- 风控详情页面混入多个其他模块的完整或半完整内容。
- `LegacyStrategyCoverage` 仍作为账户管理区域使用。
- 风险、通知、审计和系统健康状态在同一页面耦合。
- 状态语义存在英文和中文混用。
- 页面同时承担数据请求、聚合计算和多个模块展示。

## 12. 后续前端治理要求

- 保留一级和二级路由不变。
- 风控详情逐步收口为风险事件和风险摘要页面。
- 账户、报表、审计、监控和通知只在风控页展示必要摘要及跳转入口。
- 风险对象使用统一 ID 与策略、账户、订单关联。
- 风险等级和状态使用统一枚举。
- 不在风控页面继续新增与风险无直接关系的完整业务卡片。

## 13. 验收标准

- 风控管理能够清晰展示风险数量、等级、状态和关联对象。
- 风控详情以风险事件和处置为主。
- 其他模块内容仅作为必要摘要，不形成第二套完整页面。
- 风控状态和等级语义统一。
- 风险事件可以关联策略、账户、持仓、订单或系统对象。
- 当前路由结构保持不变。
