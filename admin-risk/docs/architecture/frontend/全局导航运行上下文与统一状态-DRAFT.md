## 2. 一级导航

平台一级导航固定为：

1. 首页。
2. 对冲基金看板。
3. 新闻日历与理财。
4. 策略。
5. 风险管理。
6. 金融AI分析。

规则：

- 一级导航顺序由产品架构维护。
- 技术页面、Gateway 页面和隐藏诊断路由不得自然升级为第七个一级模块。
- 无权限模块可以隐藏或显示禁用入口，具体策略由产品和安全要求决定。
- 首页可以提供模块入口，但不复制一级导航所有职责。

## 4. 路由表达原则

### 4.1 可恢复主上下文进入路由

刷新、复制链接、前进和后退需要恢复的主上下文应进入 URL。

候选内容：

- 一级模块。
- 二级模块或主要视角。
- StrategyId。
- instrumentId。
- accountId，适用且安全时。
- 对象详情 ID。
- 时间区间。
- 计价币种。
- 兼容公共筛选。

### 4.2 短期交互状态不进入路由

以下通常保留在页面本地状态：

- 未提交表单。
- 临时展开和折叠。
- 鼠标悬停。
- 图表光标。
- 临时排序，除非产品要求可分享。
- 未确认的交易数量和价格。

### 4.3 敏感内容禁止进入路由

禁止包含：

- API Key、Secret、密码和 Token。
- 完整账户凭证。
- 未脱敏个人信息。
- 能授予权限的参数。
- 完整订单、持仓和策略对象 JSON。

## 5. 全局运行上下文

### 5.1 DeploymentEnvironment

候选值：

- development。
- testing。
- staging。
- production。

用于表达软件和基础设施部署环境。

### 5.2 TradingMode

候选值：

- demo。
- simulation。
- paper。
- live。

用于表达交易资金和撮合环境。

### 5.3 TradingPermissionState

候选值：

- disabled。
- read_only。
- enabled。
- blocked。

用于表达当前用户、策略、账户、Runtime、Gateway、风险和数据质量综合形成的交易能力。

### 5.4 三者必须分开

例如：

- production 可以运行 demo。
- staging 可以连接 paper。
- production 不自动意味着 live。
- live 账户在风险阻断时 TradingPermissionState 可以是 blocked。

前端不得通过颜色、URL 或本地环境变量自行推导最终交易许可。

## 7. 上下文继承规则

### 7.1 同模块内

兼容上下文可以继承：

- StrategyId 在交易平台分析与执行之间继承。
- StrategyId 在策略管理三个视角之间继承。
- 时间区间和币种在兼容页面间继承。

不兼容上下文必须重置：

- 切换 StrategyId 后，策略特有账户和交易参数重新加载。
- 切换资产类别后，不保留无效 Instrument。
- 切换 TradingMode 后，账户和权限重新查询。

### 7.2 跨模块

仅传递稳定 ID、时间和筛选。

目标模块：

- 验证 ID。
- 验证权限。
- 重新查询数据。
- 对失效上下文安全降级。

### 7.3 无权限或不存在

深链接目标无权限、已删除或已归档时：

- 不泄露对象详情。
- 显示安全错误。
- 提供返回上级或默认入口。
- 记录必要审计，适用时。

## 8. 统一请求状态

每个远程 Query 或 Command 必须独立表达请求状态，不能用业务状态代替。

候选状态：

- idle。
- loading。
- refreshing。
- success。
- empty。
- error。
- cancelled。

规则：

- refreshing 不清空已有成功数据，除非数据已不可安全使用。
- empty 表示查询成功但没有数据，不等于 error。
- cancelled 不得显示为业务失败。
- 同一页面多个数据区块可以具有不同请求状态。

---

## 9. 统一数据状态

数据状态表达数据本身，而不是请求过程。

候选状态：

- current：当前有效。
- delayed：延迟但仍可展示。
- stale：超过有效阈值。
- partial：部分数据可用。
- missing：必要数据缺失。
- conflicting：来源冲突。
- revised：数据已修订。
- invalid：校验失败。
- unavailable：来源不可用。
- unknown：无法判定。

每个状态需要：

- 用户可理解文案。
- 来源和时间。
- 对页面和操作的影响。
- 是否允许继续交易或正式计算。

---

## 10. 统一业务操作状态

### 10.1 Command 状态

表达命令受理过程：

- preparing。
- validating。
- rejected。
- accepted。
- result_unknown。

accepted 不等于外部执行成功。

### 10.2 执行状态

由 ExecutionBatch、Order 和 Fill 各自表达，不使用一个通用 `status` 替代。

### 10.3 审批状态

审批状态独立于目标命令和目标对象状态。

### 10.4 对账状态

对账状态独立于订单、持仓和 PnL 状态。

### 10.5 AI 任务状态

分析任务状态独立于分析结果内容和人工编辑状态。

---

## 11. 统一页面状态

### 11.1 Loading

- 使用骨架或局部加载。
- 不使用虚构业务值填充。
- 关键上下文仍应可见，适用时。

### 11.2 Empty

空状态必须说明：

- 当前筛选下无数据。
- 当前用户无关联对象。
- 功能尚未配置。
- 数据源尚未接入。

不得一律显示“暂无数据”。

### 11.3 Error

错误状态至少提供：

- 用户可理解摘要。
- 是否可重试。
- requestId 或可供支持定位的标识。
- 安全返回路径。

不得在前端直接显示凭证、堆栈和敏感内部信息。

### 11.4 Stale／Delayed

必须显示：

- 数据时间。
- 延迟程度。
- 受影响指标和操作。
- 是否允许继续使用。

### 11.5 Partial

必须明确：

- 哪些数据已成功。
- 哪些数据缺失。
- 汇总是否仍可核对。
- 是否允许正式报表、交易或 AI 分析。

### 11.6 Permission Denied

区分：

- 无页面访问权限。
- 有页面权限但无目标数据权限。
- 有读取权限但无写入权限。
- 操作需要审批或更高能力。

### 11.7 Read Only

说明只读原因：

- 权限限制。
- TradingPermissionState。
- 数据质量。
- 维护状态。
- 恢复或对账中。

### 11.8 Degraded

系统降级时明确：

- 可使用功能。
- 禁止功能。
- 数据新鲜度。
- 是否允许减仓、撤单或只读。

## 12. 全局通知与消息

通知分为：

- 信息。
- 成功。
- 警告。
- 错误。
- 高风险。
- 待处理。

通知必须关联：

- 来源模块。
- 目标对象类型和 ID。
- 发生时间。
- 严重程度。
- 跳转入口。
- 是否需要操作。

Toast 只用于短期反馈，重要业务事件必须进入消息通知、风险事件、审计或目标业务记录。

## 13. 刷新与断线恢复

### 13.1 页面刷新

刷新后通过 URL、会话和后端 Query 恢复：

- 主模块和视角。
- 稳定对象 ID。
- 兼容筛选。
- 未完成业务流程的当前权威状态。

### 13.2 实时通道断线

断线后：

1. 显示连接状态。
2. 保留最后成功数据并标记时间。
3. 禁止依赖实时状态的高风险操作，按规则决定。
4. 重连后通过权威 Query 获取快照。
5. 再恢复增量事件。

实时事件不是唯一数据来源。

### 13.3 浏览器关闭

浏览器关闭不得：

- 终止已受理交易。
- 删除订单或执行批次。
- 改变 Runtime 状态。
- 取消后台报表和 AI 任务，除非用户明确发起取消命令。

## 14. 前端状态归属

### 页面本地状态

- 未提交表单。
- 临时 UI 交互。
- 草稿，按产品规则。

### 服务端业务状态

- StrategyInstance。
- TradeCommand。
- ExecutionBatch。
- Order、Fill、Position。
- PnL、Risk、Reconciliation。
- Approval、Audit。

### 实时连接状态

- WebSocket 连接。
- 最近事件时间。
- Runtime／Gateway 健康摘要。

连接状态不等于业务对象状态。

---

## 15. 验收标准

- 六个一级模块和主要视角具有稳定导航语义。
- 可恢复主上下文进入路由，敏感和短期状态不进入路由。
- DeploymentEnvironment、TradingMode 和 TradingPermissionState 分开。
- 请求状态、数据状态和业务状态分开。
- Empty、Error、Stale、Partial、Permission Denied 和 Degraded 有统一语义。
- 页面刷新和实时断线后通过权威 Query 恢复。
- 浏览器关闭不影响后台业务执行。
- 跨模块跳转只传递稳定 ID 和安全筛选。
