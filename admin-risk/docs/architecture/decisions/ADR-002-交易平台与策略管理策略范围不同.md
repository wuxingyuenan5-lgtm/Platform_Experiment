# ADR-002：交易平台与策略管理的策略范围允许不同

状态：`accepted`  
日期：2026-07-15  
适用基线：Platform V5

## 背景

交易平台承担行情分析和平台下单；策略管理承担所有纳管策略的损益、资金和订单统计。

当前策略范围为：

- 交易平台：资费套利、跨所价差、海内外价差。
- 策略管理：上述三类，加上抄底、短线交易员 L、短线交易员 W。

抄底和两类短线策略当前不需要通过本平台下单，但仍需要统一统计和管理。

## 决策

交易平台和策略管理不要求展示完全相同的策略集合。

具体规则：

- 只有需要通过平台完成行情判断和下单的策略进入交易平台。
- 所有需要被统一统计、复盘和监督的策略进入策略管理。
- 非平台执行策略不得为了结构对称而创建空的交易执行页面。
- 两个模块通过统一策略 ID 和策略注册表保持定义一致，而不是通过相同策略数量保持一致。

## 原因

- 模块职责不同，策略覆盖范围自然不同。
- 强制对齐会制造没有真实业务价值的页面。
- 策略管理必须能够纳管外部执行或人工执行的策略。

## 影响

- 交易平台读取 `platform.enabled = true` 的策略。
- 策略管理读取 `management.enabled = true` 的策略。
- 抄底和短线交易员 L/W 不进入交易平台，但必须保留策略管理能力。
- 后续新增策略时，必须分别判断其平台执行能力和管理统计能力。

## 重新讨论条件

当某个非平台执行策略需要正式通过本平台下单时，更新该策略的能力配置和对应需求文档即可，无需推翻本 ADR。
