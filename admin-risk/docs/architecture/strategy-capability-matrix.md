# 策略能力矩阵

状态：`active`  
适用基线：Platform V5

## 1. 目的

统一说明各策略在哪些模块中出现，以及具备哪些前端能力。

策略是否进入交易平台，取决于是否需要通过本平台完成下单；策略是否进入策略管理，取决于是否需要被平台统计和管理。两者不是同一判断条件。

## 4. 能力定义

### 行情分析

用于研究市场结构、交易规律、分位、联动和可交易窗口，不承担正式下单动作。

### 交易执行

用于执行前判断、参数确认、下单、配平、执行反馈和必要的持仓风险展示。

### 策略损益

用于展示策略整体结果、损益归因、收益和成本构成、净值与细分曲线。

### 账户资金

用于展示策略相关账户的资金安全、占用、效率、净值、回撤和特有风险规则。

### 订单信息

用于展示当前持仓、历史订单、成交记录、执行记录和穿透查询，不承担实时下单主操作。

## 5. 新增策略规则

新增策略时，不得直接在交易平台或策略管理页面中硬编码名称。应先确认：

1. 策略唯一 ID。
2. 策略正式名称。
3. 策略类型。
4. 是否通过交易平台下单。
5. 是否进入策略管理。
6. 是否具备行情分析、交易执行、损益、资金和订单能力。
7. 单腿、双腿或多腿结构。
8. 单账户、双账户或多账户结构。

完成确认后，再加入统一策略注册表。
