# 抄底：策略定位与需求

状态：`active`  
适用基线：Platform V5  
策略 ID：`dip`

## 1. 策略定位

抄底策略是根据价格位置、回撤、波动、成交量或其他已确认信号，在目标标的出现低位机会时建立方向性仓位的策略。

当前策略不通过本平台下单，但其持仓、损益、账户资金和订单结果需要进入策略管理统一统计。

## 2. 平台能力

| 能力 | 是否启用 |
|---|---:|
| 交易平台·行情分析 | 否 |
| 交易平台·交易执行 | 否 |
| 策略管理·策略损益 | 是 |
| 策略管理·账户资金 | 是 |
| 策略管理·订单信息 | 是 |

`platform.enabled = false` 是既定业务设计，不是待补页面。

## 3. 核心用户问题

### 策略损益

- 策略累计和区间收益是多少？
- 哪些标的贡献最大？
- 胜率、盈亏比和回撤如何？
- 止盈、止损和人工退出对结果有何影响？

### 账户资金

- 当前投入了多少资金？
- 仓位利用率如何？
- 单标的或整体仓位是否过高？
- 当前净值和回撤是否处于可接受范围？

### 订单信息

- 当前持有哪些标的？
- 哪些信号触发了开仓？
- 止盈止损是否按计划执行？
- 是否存在人工干预或异常退出？

## 4. 交易结构

### 4.1 腿模型

`single`

### 4.2 账户模型

`single`

如未来实际执行涉及多个账户，应在确认后扩展账户模型，不在当前文档中预设。

### 4.3 执行来源

当前为外部执行或人工执行结果导入策略管理。

本轮不定义：

- 平台下单页。
- 交易信号引擎。
- 自动订单路由。

## 5. 策略损益需求

### 5.1 总览

至少展示：

- 累计损益。
- 区间收益率。
- 当日或周期损益。
- 策略净值。
- 最大回撤。
- 胜率。
- 持仓标的数量。

### 5.2 归因维度

建议支持：

- 单标的贡献。
- 已实现损益。
- 未实现损益。
- 交易成本。
- 止盈贡献。
- 止损损失。
- 人工退出影响。

具体信号归因和收益归因需以后续确认的策略规则为准，不在前端组件中自行推断。

### 5.3 曲线

至少包含：

- 日度收益。
- 净值曲线。
- 回撤曲线。
- 单标的贡献曲线或排行。

## 6. 账户资金需求

至少展示：

- 策略总资金。
- 账户权益。
- 可用资金。
- 已用资金。
- 当前持仓市值。
- 仓位利用率。
- 单标的集中度。
- 策略净值。
- 当前回撤和最大回撤。

风险提示建议包括：

- 仓位利用率过高。
- 单标的集中度过高。
- 当前回撤接近限制。
- 多个标的高度相关。
- 计划止损未执行。

具体限制值应由后续策略规则确定，当前文档不虚构数值。

## 7. 订单信息需求

固定页签：

- 当前持仓。
- 历史订单。
- 成交记录。
- 执行记录。

建议增加：

- 信号触发记录。
- 止盈止损记录。
- 人工干预记录。

关键字段：

- 时间。
- 策略 ID。
- 标的。
- 信号或入场原因。
- 方向。
- 委托价和成交价。
- 数量。
- 仓位比例。
- 止盈价。
- 止损价。
- 退出原因。
- 手续费。
- 订单状态。
- 执行来源。

## 8. 风险结构

主要风险：

- 抄底后价格继续下跌。
- 多标的同步下跌。
- 仓位和标的集中度过高。
- 止损未执行。
- 流动性不足。
- 外部执行数据缺失或延迟。
- 人工干预与原策略规则不一致。

## 9. 数据进入策略管理的要求

即使不经过交易平台，数据进入策略管理后仍应使用统一语义：

- 策略 ID 固定为 `dip`。
- 每笔订单具有唯一标识。
- 持仓、订单、成交和执行记录可关联。
- 金额和收益率口径明确。
- 信号触发和人工操作可以区分。
- 外部执行来源明确标记。

当前前端阶段可以使用 Mock 数据表达上述结构。

## 10. 当前 V5 前端状态

已具备：

- 策略管理中的抄底策略入口。
- 策略损益、账户资金和订单信息三页结构。
- 基础损益、净值、资金和订单 Mock 展示。

后续本地整理重点：

- 明确真实抄底策略规则后补充信号和风险字段。
- 保证不出现交易平台下单入口。
- 将订单、信号和人工干预记录关系表达清楚。

## 11. 待业务确认事项

以下内容当前不做假设：

- 具体标的范围。
- 信号计算公式。
- 仓位计算规则。
- 止盈止损规则。
- 最大持仓数量。
- 最大仓位利用率。
- 回撤和亏损限制。

这些内容确认后应更新本文件，而不是散落在页面或临时说明中。

## 12. 明确不包含

- 交易平台行情分析页。
- 交易平台执行页。
- 自动信号生成引擎。
- 自动下单和订单路由。
- 未确认的风控阈值。

## 13. 验收标准

- 抄底策略仅出现在策略管理，不出现在交易平台。
- 具备策略损益、账户资金和订单信息三类能力。
- 能够展示单标的贡献、净值、回撤和仓位利用率。
- 当前持仓、历史订单、成交、信号和人工干预具有清晰关系。
- 未确认的策略规则以待确认事项记录，不在代码中随意硬编码。
