# 海内外价差：策略定位与需求

状态：`active`  
适用基线：Platform V5  
策略 ID：`domesticOverseas`

## 1. 策略定位

海内外价差是通过国内市场与海外市场之间的价格关系、汇率换算、期限结构和持仓成本差异建立对冲头寸，获取海内外价差回归或结构性收益的多因素双腿策略。

当前已明确的核心研究和损益口径以黄金为主，前端可以保留金、银、铜等标的切换能力，但不同金属不得在没有独立业务确认的情况下直接套用完全相同的损益参数。

## 2. 平台能力

| 能力 | 是否启用 |
|---|---:|
| 交易平台·行情分析 | 是 |
| 交易平台·交易执行 | 是 |
| 策略管理·策略损益 | 是 |
| 策略管理·账户资金 | 是 |
| 策略管理·订单信息 | 是 |

## 3. 核心用户问题

### 行情分析

- 国内价格和海外价格按统一单位、汇率换算后的价差是多少？
- 当前价差处于什么历史分位？
- 汇率、期限结构和库存费分别如何影响当前机会？
- 当前价差是否覆盖交易成本和持仓成本？
- 应选择哪个国内合约、现货标的或海外标的？

### 交易执行

- 国内腿和海外腿分别交易多少？
- 当前汇率和换算价格是多少？
- 两端名义价值和风险敞口是否匹配？
- 执行后国内外账户资金和保证金如何变化？
- 是否存在单腿、汇率或配平风险？

### 策略管理

- 累计总损益中，非汇率损益和汇率损益各是多少？
- 海内外溢价、期现价差、库存费和交易成本分别贡献多少？
- 汇率损益来自哪些本金、持仓和库存费因素？
- 配平误差来自国内腿还是海外腿？
- 国内外账户是否安全，币种和保证金结构是否合理？

## 4. 交易结构

### 4.1 交易腿

- 国内腿：国内期货、现货或对冲持仓。
- 海外腿：海外现货、差价合约、期货或其他已确认标的。

V5 当前交易场景包括但不限于：

- `SHFE / XAUUSD`。
- `AU9999 / XAUUSD`。

### 4.2 腿模型

`dual`

实际损益分析中可以对国内持仓、国内对冲持仓和海外持仓进一步穿透，但交易执行入口仍以国内腿和海外腿为主要结构。

### 4.3 账户模型

`dual`

前端必须明确展示：

- 国内账户。
- 海外账户。
- 账户币种。
- 标的和合约。
- 合约乘数。
- 数量和名义价值。
- 汇率和统一计价币种。

## 5. 价格和汇率换算口径

页面和 Mock 数据必须统一以下定义：

- 国内价格单位。
- 海外价格单位。
- 克、盎司、吨等单位换算。
- 合约乘数。
- 使用的汇率品种。
- 汇率方向。
- 买卖价、中间价或结算价口径。
- 时间同步方式。

任何主图、实时价差、统计表和执行预估都必须使用同一换算函数或同一业务配置，禁止在多个组件中分别硬编码换算公式。

## 6. 行情分析需求

必须包含：

- 金、银、铜等已配置标的切换。
- 国内交易场景选择。
- 国内腿和海外腿选择。
- 当前国内价格。
- 当前海外价格。
- 当前汇率。
- 换算后的海外价格。
- 当前海内外价差。
- 价差主图。
- 区间分位和统计。
- 期限结构。
- 库存费或持仓年化分析。
- 实时价差列表。
- 时间精度和日期区间。

### 6.1 统计分析

至少支持：

- 当前价差。
- 近一月、近一季度、近半年和近一年统计。
- 10%、50%、90% 分位。
- 区间最大值和最小值。
- 必要的均值、标准差和偏离程度。

### 6.2 图表要求

- 海内外价差作为主序列。
- 可以叠加黄金价格、汇率或其他必要参考序列。
- 支持序列显示切换。
- 支持日期区间和缩放。
- 图表和表格使用同一标的、汇率和换算上下文。

## 7. 交易执行需求

### 7.1 执行前状态

- 国内腿报价。
- 海外腿报价。
- 当前汇率。
- 统一换算后的价格。
- 当前价差。
- 目标开仓或平仓价差。
- 当前国内外持仓和账户状态。
- 当前是否允许执行。

### 7.2 执行参数

- 开仓、平仓或调整。
- 国内腿方向、价格、数量和订单类型。
- 海外腿方向、价格、数量和订单类型。
- 两腿换算比例。
- 合约乘数和数量换算。
- 价格保护或滑点参数。
- 汇率保护参数或提示。

### 7.3 执行前预估

- 预期海内外价差收益。
- 预计期现价差影响。
- 预计库存费影响。
- 预计汇率影响。
- 国内外手续费。
- 滑点和资金成本。
- 执行后的账户资金和保证金变化。

### 7.4 执行反馈

- 国内腿订单状态。
- 海外腿订单状态。
- 两腿成交数量和均价。
- 实际成交汇率。
- 实际成交价差。
- 配平状态。
- 单腿或汇率暴露。
- 失败、撤单和人工干预。

## 8. 策略损益总结构

海内外价差损益采用四层结构：

1. 累计总损益（含汇率）。
2. 累计损益（除汇率）。
3. 汇率损益。
4. 配平误差。

原则核对关系：

`累计总损益（含汇率） = 累计损益（除汇率） + 汇率损益 + 配平误差`

所有成本项必须使用统一正负号规则。

## 9. 累计损益（除汇率）

累计损益（除汇率）内部固定细分为：

- 库存费累计收益（除汇率）。
- 海内外溢价损益。
- 期现价差损益。
- 累计交易成本。

### 9.1 库存费累计收益（除汇率）

表达库存费或持仓相关收益在剔除汇率影响后的实际贡献。

### 9.2 海内外溢价损益

表达国内价格与统一换算后的海外价格之间溢价变化带来的核心策略损益。

### 9.3 期现价差损益

表达国内或海外相关期货、现货及期限结构变化带来的损益。

### 9.4 累计交易成本

至少包含：

- 国内手续费。
- 海外手续费。
- 已确认滑点成本。
- 其他明确归属于交易执行的成本。

## 10. 汇率损益

汇率损益固定细分为：

- 海外本金汇率损益。
- 库存费汇率损益。
- 国内汇率变动持仓损益。
- 海外持仓汇率损益。
- 国内对冲持仓汇率损益。

### 10.1 海外本金汇率损益

表达海外账户本金或基础资金因汇率变化产生的折算损益。

### 10.2 库存费汇率损益

表达库存费收益或成本在产生、持有和折算过程中受到汇率变化影响的部分。

### 10.3 国内汇率变动持仓损益

表达汇率变化对国内相关持仓换算价值产生的损益影响。

### 10.4 海外持仓汇率损益

表达海外持仓在统一计价币种下因汇率变化产生的损益。

### 10.5 国内对冲持仓汇率损益

表达国内对冲持仓因汇率变化产生的折算损益。

## 11. 配平误差

配平误差固定细分为：

- 海外持仓损益（除汇率）。
- 国内对冲持仓损益（除汇率）。

配平误差用于表达实际持仓与理论配平关系之间的差异损益。

该项不得与以下内容重复：

- 汇率损益。
- 海内外溢价损益。
- 期现价差损益。
- 已经归入交易成本的滑点。

配平误差的定义、理论持仓和实际持仓必须在后续数据模型中可以核对；当前前端阶段先保留明确展示结构。

## 12. 策略损益页面需求

页面必须支持：

- 累计总损益（含汇率）总览。
- 四个一级损益板块的金额和占比。
- 累计损益（除汇率）的四项细分。
- 汇率损益的五项细分。
- 配平误差的两项细分。
- 总损益曲线。
- 各一级和二级损益曲线。
- 按时间区间查看。
- 必要时按账户、标的或执行批次穿透。

## 13. 账户资金需求

### 13.1 合并总览

- 策略总资金。
- 合并权益。
- 统一计价币种下的可用资金。
- 总保证金占用。
- 资金使用率。
- 策略净值。
- 最大回撤。

### 13.2 国内账户

- 账户和币种。
- 现金和可用资金。
- 持仓和名义价值。
- 保证金占用。
- 国内对冲持仓。
- 风险状态。

### 13.3 海外账户

- 账户和币种。
- 海外本金。
- 可用资金。
- 持仓和名义价值。
- 保证金占用。
- 汇率折算价值。
- 风险状态。

### 13.4 风险提示

- 国内外资金失衡。
- 币种集中度过高。
- 汇率暴露过大。
- 单端保证金不足。
- 理论与实际配平差异扩大。
- 市场交易时间不一致。

## 14. 订单信息需求

固定页签：

- 当前持仓。
- 历史订单－国内。
- 历史订单－海外。
- 对冲订单。
- 成交记录。
- 执行记录。

关键字段：

- 时间。
- 策略 ID。
- 执行批次 ID。
- 国内或海外腿类型。
- 平台和账户。
- 币种。
- 标的和合约。
- 方向。
- 委托价和成交价。
- 委托量和成交量。
- 成交汇率。
- 手续费。
- 订单状态。
- 理论持仓和实际持仓。
- 人工干预记录。

## 15. 风险结构

主要风险：

- 海内外价差继续扩大。
- 汇率不利变化。
- 国内外市场交易时间不一致。
- 单腿成交和单腿暴露。
- 理论与实际持仓不配平。
- 期现结构变化。
- 库存费或持仓成本变化。
- 合约规格和单位换算错误。
- 国内外账户保证金不足。

## 16. 当前 V5 前端状态

已具备：

- 金、银、铜标的切换。
- 国内外场景和腿选择。
- 海内外价差主图。
- 价差分析、实时价差和统计区。
- 行情分析和交易执行分离。
- 策略管理中的损益、资金和订单入口。

后续本地整理重点：

- 将所有换算逻辑收口为统一配置或函数。
- 按本文档统一损益名称和层级。
- 保证损益总览、细分表和曲线使用同一口径。
- 将理论持仓、实际持仓和配平误差关系表达清楚。

## 17. 明确不包含

- 未经单独确认的其他金属损益公式。
- 完整宏观汇率研究体系。
- 后端交易和资金系统实现。
- 将跨所价差的简化损益结构直接套用到本策略。

## 18. 验收标准

- 交易平台具备完整行情分析和交易执行。
- 国内外价格、单位、合约乘数和汇率换算口径一致。
- 策略管理具备完整四层损益结构。
- 累计损益（除汇率）包含四项固定细分。
- 汇率损益包含五项固定细分。
- 配平误差包含两项固定细分。
- 累计总损益能够与各一级损益核对。
- 国内外账户、币种、保证金和汇率暴露表达清晰。
- 国内、海外、对冲和执行记录可以穿透查询。
