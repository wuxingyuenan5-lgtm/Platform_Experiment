# 短线交易员 L：策略定位与需求

状态：`active`  
适用基线：Platform V5  
策略 ID：`shortLineTraderL`

## 1. 策略定位

短线交易员 L 是纳入平台统一统计和风险观察的独立短线交易策略账户。

该策略当前不通过交易平台下单，策略管理只接收并展示其外部执行结果、账户状态、订单档案和风险记录。

短线交易员 L 与短线交易员 W 可以共享管理页面骨架，但必须保持：

- 独立策略 ID。
- 独立账户。
- 独立损益。
- 独立订单记录。
- 独立风险和违规状态。

## 2. 平台能力

| 能力 | 是否启用 |
|---|---:|
| 交易平台·行情分析 | 否 |
| 交易平台·交易执行 | 否 |
| 策略管理·策略损益 | 是 |
| 策略管理·账户资金 | 是 |
| 策略管理·订单信息 | 是 |

`platform.enabled = false` 是既定业务设计。

## 3. 核心用户问题

### 策略损益

- 当日和区间赚了多少钱？
- 收益主要来自哪些标的、时段或交易？
- 交易成本和异常损失是多少？
- 当前表现是否稳定，是否伴随过大回撤？

### 账户资金

- 当前账户权益和可用资金是多少？
- 当日亏损、总回撤和风险额度是否接近限制？
- 当前是否允许继续交易？
- 是否存在违规或需要人工处理的状态？

### 订单信息

- 当前持仓和当日订单是什么？
- 历史成交和执行结果如何？
- 是否存在失败、撤单、超限或人工干预？
- 具体风险事件能否关联到订单和时间？

## 4. 交易结构

### 4.1 腿模型

`single`

短线交易员策略以独立交易账户为主要管理对象，不采用套利策略的双腿配平模型。

### 4.2 账户模型

`single`

如果未来确认该交易员同时管理多个账户，应通过账户维度扩展，不改变策略 ID。

### 4.3 执行来源

当前为外部交易终端、人工交易或其他已确认来源。

策略管理不提供正式下单入口。

## 5. 策略损益需求

### 5.1 总览

至少展示：

- 当日损益。
- 本周损益。
- 本月损益。
- 自定义区间损益。
- 区间收益率。
- 策略净值。
- 最大回撤。
- 交易次数。
- 胜率。

### 5.2 归因维度

建议支持：

- 按标的归因。
- 按交易时段归因。
- 按多空方向归因。
- 已实现损益。
- 未实现损益。
- 手续费和交易成本。
- 异常损失或违规相关损益。

具体归因维度应以交易员 L 的实际交易规则和数据来源为准。

### 5.3 曲线

至少包含：

- 日度收益。
- 净值曲线。
- 回撤曲线。
- 当日累计损益曲线或区间损益曲线。

## 6. 账户资金需求

至少展示：

- 初始资金或统计基准资金。
- 当前账户权益。
- 可用资金。
- 已用保证金。
- 当前持仓名义价值。
- 当日损益。
- 当日最大亏损。
- 当前回撤。
- 最大回撤。
- 当前风险额度。
- 是否允许继续交易。

### 6.1 专属风险卡片

建议展示：

- 日内亏损限制状态。
- 总回撤限制状态。
- 单笔风险或持仓风险状态。
- 违规次数。
- 当前账户状态。
- 最近风险事件。

具体限制数值必须后续确认，不在当前文档中虚构。

## 7. 订单信息需求

固定页签：

- 当前持仓。
- 历史订单。
- 成交记录。
- 执行记录。

建议增加：

- 风险事件。
- 违规记录。
- 人工干预记录。

关键字段：

- 时间。
- 策略 ID。
- 账户。
- 标的。
- 方向。
- 订单类型。
- 委托价和成交价。
- 委托量和成交量。
- 止损和止盈信息。
- 已实现损益。
- 手续费。
- 订单状态。
- 风险事件类型。
- 是否人工干预。
- 执行来源。

## 8. 风险结构

主要风险：

- 日内亏损超限。
- 总回撤超限。
- 单笔或单标的风险过高。
- 持仓集中度过高。
- 高频连续亏损。
- 未按规则止损。
- 外部执行数据缺失或延迟。
- 人工操作与规则不一致。

当前前端阶段要求展示风险结果和事件记录，不定义完整风控计算引擎。

## 9. 数据进入策略管理的要求

- 策略 ID 固定为 `shortLineTraderL`。
- 账户、订单、成交、持仓和风险事件可关联。
- 每条记录标明执行来源。
- 当日和区间口径明确。
- 亏损限制和回撤限制使用同一统计基准。
- 违规状态不通过颜色单独表达，必须附带文字状态。

## 10. 当前 V5 前端状态

已具备：

- 策略管理中的短线交易员 L 入口。
- 策略损益、账户资金和订单信息三页结构。
- 基础 Mock 数据和风险卡片结构。

后续本地整理重点：

- 明确交易员 L 的真实风险规则。
- 补齐风险事件与订单之间的关联。
- 保证与交易员 W 共用骨架但不共用数据。
- 不增加交易平台下单入口。

## 11. 待业务确认事项

- 可交易标的范围。
- 交易时间范围。
- 初始或基准资金。
- 日内亏损限制。
- 总回撤限制。
- 单笔风险限制。
- 持仓和集中度限制。
- 新闻或隔夜持仓规则。
- 违规判定和处置方式。

## 12. 明确不包含

- 交易平台行情分析。
- 交易平台交易执行。
- 自动下单和复制交易功能。
- 未经确认的风险阈值。
- 与交易员 W 合并统计。

## 13. 验收标准

- 短线交易员 L 仅出现在策略管理，不出现在交易平台。
- 损益、账户和订单数据保持独立。
- 能够展示当日损益、区间损益、净值和回撤。
- 能够展示账户风险额度、限制状态和违规事件。
- 订单、成交、执行和风险事件可以相互穿透。
- 未确认规则集中记录在本文档，不在页面中随意硬编码。
